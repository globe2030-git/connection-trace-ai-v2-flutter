# 테스터 안내문 (배포 시 그대로 전달)

이 문서는 **직원 테스터에게 보내는 안내문의 원본**이다. 배포할 때마다 새로
쓰지 말고 이 문서를 고쳐 쓴다 — 매번 새로 쓰면 릴리스 노트와 내용이 어긋나고,
"지금 안 되는 기능" 목록이 빠져 정상 상태를 결함으로 제보받는다.

**갱신 규칙**

- 기능이 추가·제거되면 "지금은 안 되는 기능" 절을 **먼저** 고친다.
- **"이번 배포에서 달라진 것"은 배포할 때마다 갈아 끼운다.** 지난 배포분이
  남아 있으면 테스터가 이미 확인한 것을 또 보게 된다. 목록은
  `git log --no-merges <지난배포해시>..main -- lib/`로 뽑되, **사용자에게
  보이는 것만** 남긴다(관리자 전용 도구·서버 보안 수정은 뺀다).
- **"먼저 해 주실 일"은 이번 배포에만 해당한다.** 다음 배포 때 초기화를
  요구하지 않으면 그 절을 통째로 지운다 — 남겨 두면 테스터가 매번 지운다.
- 앱 버전(빌드 해시)은 배포할 때마다 바꾼다.
- 중점 사항의 우선순위는 그때 **가장 알고 싶은 것**을 1순위로 올린다.
  전부 중요하다고 하면 아무것도 중점이 되지 않는다.

## 커넥션센스 테스트 안내

### 이 앱이 하는 일

**명함을 등록해 두면, 그 사람 근처에 갔을 때 알려주고 무슨 말을 꺼낼지 AI가
만들어 줍니다.**

명함첩 앱은 많지만 대부분 "저장"에서 끝납니다. 커넥션센스는 저장한 인맥을
**다시 만나는 순간**에 초점을 맞췄습니다.

1. 명함을 카메라로 찍거나 직접 입력해 등록
2. 등록한 사람의 회사 주소 근처에 가면 "주변 인맥"에 뜸
3. 연락하기 전에 **AI 대화 가이드**를 열면, 그 사람과의 기록을 바탕으로
   꺼낼 말 3가지를 만들어 줌
4. 만든 문장을 통화·문자·카톡·메일로 바로 전달

### 설치

**이번 빌드: `1.0.0+12`** — 설치 뒤 **설정 → 앱 버전**에서 확인하실 수 있습니다.

초대 메일의 링크로 설치하시면 됩니다. **"출처를 알 수 없는 앱" 경고**가 뜨면
허용해 주세요 — 스토어를 거치지 않은 테스트 빌드라 정상입니다.

---

### 🚨 먼저 해 주실 일 — 이번에는 앱이 **두 개**로 보입니다 (안드로이드)

앱의 내부 이름(패키지)이 바뀌었습니다. 그래서 이번 빌드는 **기존 앱을 덮어쓰지
않고 따로 설치**됩니다.

⚠️ **이름과 아이콘이 똑같아서 겉으로는 구분이 안 됩니다.** 옛 앱을 계속 쓰시면
"업데이트가 안 왔다"고 느끼시게 됩니다.

**이렇게 해 주세요.**

1. 새 앱을 설치하고 **로그인**합니다 (쓰시던 계정 그대로).
2. **설정 → 앱 버전**을 열어 **`1.0.0+12`** 인지 확인합니다. ← 여기가 새 앱입니다
3. 명함이 **평소처럼 다 보이는지** 확인합니다. 사진도 함께 돌아옵니다
   (명함 글자와 사진 모두 서버에서 복원됩니다).
4. **다 확인되면 옛 앱을 지워 주세요.** 3번이 안 됐다면 **지우지 마시고
   알려 주세요.**

📌 **계정과 명함은 그대로입니다** — 로그인 계정이 같으면 서버에 있던 명함이
그대로 내려옵니다. 새로 등록하실 필요 없습니다.

💡 **어느 것이 새 앱인지 헷갈리시면** 둘 다 열어 `설정 → 앱 버전`을 비교해
주세요. 숫자가 큰 쪽이 이번 빌드입니다.

📱 **아이폰(TestFlight)은 해당 없습니다** — 평소처럼 덮어 설치되고, 앱도 하나만
남습니다. `설정 → 앱 버전`이 `1.0.0+12`인지만 확인해 주세요.

### 이번 배포에서 달라진 것

지난 빌드(**+10**, 8월 24일) 이후 고친 것들입니다. **여기 적힌 대로 안 되면
그게 바로 제보 대상입니다.**

⚠️ **11일치라 양이 많습니다.** 전부 보시라는 뜻이 아니라, **아래 「중점적으로
봐 주실 것」부터** 보시고 나머지는 쓰시다 눈에 걸리는 것만 알려 주시면 됩니다.

#### ⭐ 회원가입·로그인 — 이번에 가장 크게 바뀌었습니다

- **이메일로 가입**할 수 있습니다. 전에는 구글·카카오·네이버·애플만 됐습니다.
  - 가입하시면 **인증 메일**이 갑니다. 링크를 눌러야 가입이 끝납니다
  - ⚠️ **받은편지함에 안 오면 스팸함을 봐 주시고, 그 사실을 꼭 알려 주세요**
- **동의 화면이 하나로 합쳐졌습니다.** 약관·개인정보·만 14세·광고 수신을
  한 화면에서 보시게 됩니다.
  - **광고 수신은 선택입니다** — 안 하셔도 앱을 쓰시는 데 아무 지장이 없습니다
  - 「나중에 할게요」를 고르시면 **30일 뒤에** 다시 여쭙습니다
- **만 14세 확인**을 안 하시고 로그인 버튼을 누르면 **왜 안 눌리는지** 말해
  줍니다(전에는 아무 말 없이 안 눌렸습니다).
- 지난번에 쓰신 로그인 방법에 **「최근」 표시**가 붙습니다.
- **앱 잠금**이 생겼습니다 — 설정에서 켜시면 앱을 열 때 지문·얼굴로 잠급니다.
- **폰을 잃어버렸을 때** 계정을 지우지 않고 **다른 기기의 로그인만 끊는** 길이
  생겼습니다(설정 → 로그인 기기 관리).

#### 🚨 명함 사진이 이제 서버에 백업됩니다 (전에는 기기에만 있었습니다)

- 기존에 등록하신 사진도 **자동으로 서버에 올라갑니다**(한 번만).
- 그래서 **앱을 지웠다 다시 깔아도 사진이 돌아옵니다.** 이번 패키지 교체에서도
  이 경로로 복원됩니다.
- 사진은 **암호화해서** 보관하고, **설정 → 계정 삭제** 시 함께 지워집니다.
- 한도는 **2,000장**입니다(무료·충전 구분 없이 하나).
- ⚠️ **확인 부탁**: 설정 화면의 백업 장수가 **실제 명함 수와 맞는지** 봐 주세요.

#### 명함 그룹

- **명함을 묶어 분류**할 수 있습니다(예: "삼성전자 사람들"). 이번 빌드부터
  켜져 있습니다.

#### 명함 등록 — 흐름이 바뀌었습니다

- **명함 등록이 하단 탭 4번째 자리**로 옮겨졌습니다.
- **연속 등록**이 됩니다 — 저장하면 끊기던 흐름을 이었습니다. 여러 장을 이어서
  넣으실 때 편합니다.
- 저장했는데 **화면이 안 닫히던** 것을 고쳤습니다.
- 합치기가 **방금 찍은 사진을 버리던** 것을 고쳤습니다.
- **이전 명함 기록이 저장하면 사라지던** 것을 막았습니다.
- 앱이 **명함에 없는 직함을 지어내 저장하던** 것을 멈췄습니다.
- **내 명함도 앞뒤면 스캔**이 되고, **내 명함 사진**이 화면에 보입니다.
- 같은 사람 판정을 **「이름 + 휴대폰」**으로 통일했습니다 — 중복 등록이 줄어듭니다.

#### 명함 인식 (자동 채움) — 스무 건 넘게 고쳤습니다

- **직함 뒤에 붙은 영문**(`과장 / Section Manager`)이 잘리던 것
- **회사명 앞뒤의 영문 로고**를 회사 이름으로 읽던 것
- **부서가 회사 칸에** 들어가던 것, **한 줄로 따로 인쇄된 부서**를 못 잡던 것
- **공공기관·시도 이름으로 시작하는 조직명**을 주소로 잡던 것
- **이메일이 쉼표·마침표에서 잘리던** 것
- **전화번호 구분자**를 한 글자만 보던 것
- **띄어 인쇄된 이름**을 이어 붙이지 못하던 것
- ⚠️ 그래도 틀리는 명함이 있습니다. **그 명함 사진과 함께** 알려 주시면 그게
  가장 큰 도움이 됩니다.

#### 명함 내보내기·전달

- **명함을 폰 주소록으로 내보낼** 수 있습니다(명함 상세 아래 [내보내기]).
  - 주소록에 저장할 **이름 형식을 고를** 수 있습니다
  - 내보내기 전에 **무엇이 나가는지 미리** 보여 드립니다
- **카카오톡·문자로 명함 전달**이 안 되던 것을 고쳤습니다.
- 여러 장 한 번에 스캔한 결과를 **표로 내보낼 때 부서 칸**이 함께 나갑니다.

#### 주소·주변·지도

- 같은 주소를 **두 번 물어보지 않습니다.**
- 명함 상세에서 **「주변에서 왜 이렇게 보이는지」**를 알려 줍니다.
- 지도에서 **회사명 라벨이 서로 겹쳐 가운데 것만 읽히던** 것을 고쳤습니다.
- 설정의 **「백필」**이라는 말을 **「좌표 채우기」**로 바꿨습니다(뜻을 물어보신
  분이 계셨습니다).

#### 설정·그 밖

- 설정 항목을 **성격대로 다시 묶었습니다** — 「약관 및 정책」이 잡동사니
  서랍이었습니다.
- **AI가 실패했을 때 「이 오류 신고하기」**를 누르면 문의 화면에 내용이 채워진
  채로 열립니다.
- 아이콘만 있던 버튼 **15곳에 이름**을 붙였습니다(TalkBack 등 화면 읽기 프로그램
  이용 시 무슨 버튼인지 읽힙니다).

### 🎯 중점적으로 봐 주실 것 (우선순위 순)

#### 1순위 — 가입과 로그인이 끝까지 되는가

⭐ **이번에 가장 크게 바뀐 곳이고, 저희가 가장 알고 싶은 것입니다.**

- **이메일로 새로 가입**해 보세요(쓰시던 계정 말고 새 주소로 한 번).
  - 인증 메일이 **받은편지함에** 오는지 ⚠️ **스팸함으로 갔다면 꼭 알려 주세요**
  - 인증 링크를 누른 뒤 **로그인이 되는지**
  - **비밀번호를 틀리게** 넣어 보고, **없는 주소로도** 로그인해 보세요 —
    화면이 뭐라고 하는지 알려 주시면 됩니다
  - **비밀번호 재설정**도 한 번 눌러 봐 주세요
- **동의 화면**에서
  - 필수만 고르고 **광고 수신은 끄고** 넘어가도 앱이 정상으로 쓰이는지
  - **뒤로가기**를 눌렀을 때 무슨 일이 생기는지
  - 나중에 **설정 → 광고성 정보 수신**에서 껐다 켰다 하고 **[저장]** 을
    눌렀을 때 **화면이 닫히고 값이 바뀌어 있는지** ← 최근에 고친 자리입니다
- **쓰시던 소셜 계정(구글·카카오·네이버·애플)으로도** 로그인해 보세요.
  특히 **애플 로그인**은 저희가 아직 못 눌러 봤습니다.

#### 2순위 — 명함 등록이 실제로 쓸 만한가

**이게 안 되면 나머지는 의미가 없습니다.**

- 카메라로 명함을 찍었을 때 **이름·회사·직함·부서·전화·이메일·주소가 제대로
  들어가는지**
- 특히 **주소**를 잘 읽는지 (주변 인맥 기능이 주소에 달려 있습니다)
- 세로형 명함, 영문 명함, 로고가 큰 명함 등 **다양한 형태로** 시도해 주세요
- 잘못 읽은 명함이 있으면 **그 명함 사진과 함께** 알려주시면 큰 도움이 됩니다
- **바뀐 흐름도 봐 주세요**: 하단 탭 4번째의 등록 자리, 저장 뒤 **연속 등록**,
  앞뒤면 이어찍기, 편집에서 사진 확대

#### 3순위 — 명함 사진이 서버에서 제대로 돌아오는가

🚨 **이번에 처음 켜진 기능이라 실물 확인이 필요합니다.**

- 설정 화면의 **백업 장수가 실제 명함 수와 맞는지**
  (숫자가 안 맞으면 **앱을 껐다 켜고** 다시 봐 주세요 — 시작 시점 값입니다)
- 위 「먼저 해 주실 일」에서 **새 앱에 사진이 다 돌아왔는지**
- ⚠️ **안 돌아온 명함이 있으면 옛 앱을 지우지 마시고** 알려 주세요

#### 4순위 — AI 대화 가이드가 쓸 만한가

⚠️ **두 가지를 갈라서 봐 주세요.** 저희가 고친 것과 아직 못 고친 것이 다릅니다.

**(가) 매번 다른 말이 나오는가** — 이건 고쳤습니다

- **"다시 만들기"를 여러 번** 눌러 보세요
- 누를 때마다 **문장 3개가 전부 달라지는지**
- ⚠️ 같은 말이 또 나오면 **고친 것이 안 먹은 것**이니 꼭 알려주세요

**(나) 그 문장이 쓸 만한가** — 이건 아직 손대지 않았습니다

- 실제로 **보낼 만한 수준인지**
- 어색하다면 **어떤 점이** 어색한지 (딱딱함 / 뻔함 / 사실과 안 맞음)
- 📌 *"매번 다르긴 한데 셋 다 별로다"* 같은 답이 저희에게 가장 쓸모 있습니다

**(다) 실패했을 때**

- AI가 실패하면 **「이 오류 신고하기」**가 뜹니다. 눌러서 **문의 화면이 내용이
  채워진 채로 열리는지** 봐 주세요 ← 새로 만든 자리입니다

#### 5순위 — 주변 인맥·지도

- **위치가 엉뚱한 사람이 있는지** ⚠️ 엉뚱한 위치는 없는 것보다 나쁩니다 —
  화면에는 정상으로 보이고 지도를 열어야 틀린 것이 보입니다. 이상한 곳에 찍힌
  명함이 있으면 **그 명함의 주소와 함께** 알려 주세요
- 실제로 가까이 있는 사람이 뜨는지, **거리 표시가 맞는지**
- 같은 건물에 여러 명일 때 **회사 이름 라벨이 서로 겹치지 않는지** ← 고친 자리
- 명함 상세의 **「주변에서 왜 이렇게 보이는지」** 안내가 말이 되는지

#### 6순위 — 쓰다가 불편하거나 이상한 곳

- 버튼을 눌렀는데 **아무 일도 안 일어나는** 곳
- 글자가 잘리거나 겹치는 곳
- **"이건 왜 이렇게 되지?"** 싶은 모든 순간

## 배포하는 사람이 확인할 것 (테스터에게 보내지 않는 부분)

1. **release 빌드인지** — debug에는 로그인 화면에 "로그인 건너뛰기" 버튼이
   그대로 보인다.
2. **배포 후 관리자 콘솔에 로그인 이메일 등록**
   (https://connection-sense-admin.web.app → 테스터 관리). 안 하면 App Check에
   막혀 AI가 전부 실패한다. **초대 이메일과 로그인 이메일이 다를 수 있다.**
3. **"지금 안 되는 기능" 목록이 최신인지** — 이 목록이 낡으면 정상 동작을
   결함으로 제보받아 서로 시간을 버린다.
4. 위 안내문의 **앱 버전 예시 값**을 이번 빌드 해시로 교체.
5. **"이번 배포에서 달라진 것"이 이번 빌드 내용인지** — 지난 배포분이 남아
   있으면 테스터가 이미 본 것을 또 확인한다.
6. **"먼저 해 주실 일"(초기화)이 이번 배포에도 해당하는지** — 해당 없으면
   그 절을 지운다. 남겨 두면 테스터가 매번 명함을 지운다.
   🚨 **+12 의 「앱이 두 개로 보입니다」 절은 이번 배포 한정이다.** 다음
   배포에서는 덮어 설치되므로 **그때 통째로 지운다** — 남겨 두면 테스터가
   있지도 않은 옛 앱을 찾는다.
7. **App Distribution 앱 ID 가 새 패키지 것인지**
   (`release-checklist.md` 6-1 — 옛 패키지 ID 가 박혀 있던 전례가 있다).
8. **테스터가 새 앱으로 옮긴 것을 확인하기 전에는 Firebase 의 옛 안드로이드
   앱을 지우지 않는다** — 지우면 아직 옛 앱을 쓰는 테스터가 그 자리에서
   로그인 불가가 된다(HANDOFF 1-5 ④→⑤).
