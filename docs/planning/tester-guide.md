# 테스터 안내문 (배포 시 그대로 전달)

이 문서는 **직원 테스터에게 보내는 안내문의 원본**이다. 배포할 때마다 새로
쓰지 말고 이 문서를 고쳐 쓴다 — 매번 새로 쓰면 릴리스 노트와 내용이 어긋나고,
"지금 안 되는 기능" 목록이 빠져 정상 상태를 결함으로 제보받는다.

**갱신 규칙**

- 기능이 추가·제거되면 "지금은 안 되는 기능" 절을 **먼저** 고친다.
- 앱 버전(빌드 해시)은 배포할 때마다 바꾼다.
- 중점 사항의 우선순위는 그때 **가장 알고 싶은 것**을 1순위로 올린다.
  전부 중요하다고 하면 아무것도 중점이 되지 않는다.

---

## 커넥션센스 테스트 안내

### 이 앱이 하는 일

**명함을 등록해 두면, 그 사람 근처에 갔을 때 알려주고 무슨 말을 꺼낼지 AI가
만들어 줍니다.**

명함첩 앱은 많지만 대부분 "저장"에서 끝납니다. 커넥션센스는 저장한 인맥을
**다시 만나는 순간**에 초점을 맞췄습니다.

1. 명함을 카메라로 찍거나 직접 입력해 등록
2. 등록한 사람의 회사 주소 근처에 가면 "주변 인맥"에 뜸
3. 연락하기 전에 **AI 대화 가이드**를 열면, 그 사람과의 기록을 바탕으로
   꺼낼 말 3가지를 만들어 줌
4. 만든 문장을 통화·문자·카톡·메일로 바로 전달

### 설치

초대 메일의 링크로 설치하시면 됩니다. **"출처를 알 수 없는 앱" 경고**가 뜨면
허용해 주세요 — 스토어를 거치지 않은 테스트 빌드라 정상입니다.

---

### 🎯 중점적으로 봐 주실 것 (우선순위 순)

#### 1순위 — 명함 등록이 실제로 쓸 만한가

**가장 중요합니다.** 이게 안 되면 나머지는 의미가 없습니다.

- 카메라로 명함을 찍었을 때 **이름·회사·직함·전화·이메일·주소가 제대로
  들어가는지**
- 특히 **주소**를 잘 읽는지 (주변 인맥 기능이 주소에 달려 있습니다)
- 세로형 명함, 영문 명함, 로고가 큰 명함 등 **다양한 형태로** 시도해 주세요
- 잘못 읽은 명함이 있으면 **그 명함 사진과 함께** 알려주시면 큰 도움이 됩니다

#### 2순위 — AI 대화 가이드가 쓸 만한가

- 만들어진 문장 3개가 **실제로 보낼 만한 수준인지**, 아니면 어색한지
- 어색하다면 **어떤 점이** 어색한지 (너무 딱딱함 / 뻔함 / 사실과 안 맞음 등)
- 소통 기록을 넣었을 때와 안 넣었을 때 **결과가 달라지는지**
- 문자·카톡·메일로 보낼 때 **내용이 제대로 담기는지**

#### 3순위 — 주변 인맥이 맞게 뜨는가

- 실제로 가까이 있는 사람이 뜨는지, **거리 표시가 맞는지**
- 감지 반경(500m~5km)을 바꿨을 때 목록이 달라지는지
- **지도에서 크게 보기**로 위치가 맞게 찍히는지

#### 4순위 — 쓰다가 불편하거나 이상한 곳

- 버튼을 눌렀는데 **아무 일도 안 일어나는** 곳
- 글자가 잘리거나 겹치는 곳
- **"이건 왜 이렇게 되지?"** 싶은 모든 순간

---

### 지금은 안 되는 기능 (결함이 아닙니다)

제보 전에 한 번 확인해 주세요.

- **지도가 해외 지도**라 한글 지번·건물 이름이 성깁니다 — 국내 지도 연동 준비 중
- **Gmail에서 메일 가져오기 없음**
- **통화·문자 기록을 자동으로 가져오지 않습니다** — 남기고 싶은 내용만 직접
  적거나 붙여넣는 방식입니다. 의도된 설계입니다
- **백그라운드 알림 없음** — 앱을 열었을 때 주변 인맥을 보여줍니다
- **AI는 하루 20회**까지

### AI가 "응답을 받지 못했어요"로 뜨면

**앱에서 로그인하신 이메일**을 관리자에게 알려주세요. 등록이 필요합니다.
초대받은 메일 주소와 다를 수 있습니다.

---

### ⚠️ 개인정보 관련 부탁

이 앱은 **다른 사람(명함 주인)의 개인정보**를 다룹니다.

- 테스트에는 가급적 **본인 명함이나 동의를 받은 분의 명함**을 써 주세요
- 입력한 정보는 **실제 서버에 저장**됩니다
- **테스트가 끝나면 설정 → 계정 삭제(회원 탈퇴)** 로 정리해 주세요. 계정과
  서버 백업이 함께 지워집니다

### 제보하실 때

```
[무엇을 하려다] 명함 등록에서 카메라로 찍었는데
[무엇이 일어났나] 주소가 빈칸으로 들어옴
[기대한 것] 주소가 자동으로 채워질 줄 알았음
[앱 버전] 설정 → 앱 버전의 값 (예: b295e63)
[기기] 갤럭시 S24 / 안드로이드 14
```

**앱 버전 값을 꼭 함께** 적어 주세요. 어느 빌드에서 생긴 문제인지 바로 찾을
수 있습니다. 화면 캡처가 있으면 더 좋습니다.

---

### 이것도 알려주시면 좋습니다

기능 오류가 아니어도 좋습니다.

- **"이 기능이 있으면 쓰겠다"**
- **"이건 없어도 될 것 같다"**
- 실제 영업·미팅 상황에서 **써 볼 만하다고 느꼈는지**

## 배포하는 사람이 확인할 것 (테스터에게 보내지 않는 부분)

1. **release 빌드인지** — debug에는 로그인 화면에 "로그인 건너뛰기" 버튼이
   그대로 보인다.
2. **배포 후 관리자 콘솔에 로그인 이메일 등록**
   (https://connection-sense-admin.web.app → 테스터 관리). 안 하면 App Check에
   막혀 AI가 전부 실패한다. **초대 이메일과 로그인 이메일이 다를 수 있다.**
3. **"지금 안 되는 기능" 목록이 최신인지** — 이 목록이 낡으면 정상 동작을
   결함으로 제보받아 서로 시간을 버린다.
4. 위 안내문의 **앱 버전 예시 값**을 이번 빌드 해시로 교체.

### 테스트가 끝난 뒤 (잊기 쉬움)

- `DAILY_LIMIT` 20 → 10 (두 파일) + `firebase deploy --only functions`
  — HANDOFF **P0-11**
- `enforceAppCheck: true` 복원
- `config/testers` 비우기 — 허용목록은 **App Check 우회 권한**이라 테스트가
  끝나면 닫아야 한다
