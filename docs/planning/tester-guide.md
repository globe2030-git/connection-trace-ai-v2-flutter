# 테스터 안내문 (배포 시 그대로 전달)

이 문서는 **직원 테스터에게 보내는 안내문의 원본**이다. 배포할 때마다 새로
쓰지 말고 이 문서를 고쳐 쓴다 — 매번 새로 쓰면 릴리스 노트와 내용이 어긋나고,
"지금 안 되는 기능" 목록이 빠져 정상 상태를 결함으로 제보받는다.

**갱신 규칙**

- 기능이 추가·제거되면 "지금은 안 되는 기능" 절을 **먼저** 고친다.
- **"이번 배포에서 달라진 것"은 배포할 때마다 갈아 끼운다.** 지난 배포분이
  남아 있으면 테스터가 이미 확인한 것을 또 보게 된다. 목록은
  `git log --no-merges <지난배포해시>..main -- lib/`로 뽑되, **사용자에게
  보이는 것만** 남긴다(관리자 전용 도구·서버 보안 수정은 뺀다).
- **"먼저 해 주실 일"은 이번 배포에만 해당한다.** 다음 배포 때 초기화를
  요구하지 않으면 그 절을 통째로 지운다 — 남겨 두면 테스터가 매번 지운다.
- 앱 버전(빌드 해시)은 배포할 때마다 바꾼다.
- 중점 사항의 우선순위는 그때 **가장 알고 싶은 것**을 1순위로 올린다.
  전부 중요하다고 하면 아무것도 중점이 되지 않는다.

## 커넥션센스 테스트 안내

### 이 앱이 하는 일

**명함을 등록해 두면, 그 사람 근처에 갔을 때 알려주고 무슨 말을 꺼낼지 AI가
만들어 줍니다.**

명함첩 앱은 많지만 대부분 "저장"에서 끝납니다. 커넥션센스는 저장한 인맥을
**다시 만나는 순간**에 초점을 맞췄습니다.

1. 명함을 카메라로 찍거나 직접 입력해 등록
2. 등록한 사람의 회사 주소 근처에 가면 "주변 인맥"에 뜸
3. 연락하기 전에 **AI 대화 가이드**를 열면, 그 사람과의 기록을 바탕으로
   꺼낼 말 3가지를 만들어 줌
4. 만든 문장을 통화·문자·카톡·메일로 바로 전달

### 설치

**이번 빌드: `1.0.0+9`** — 설치 뒤 **설정 → 앱 버전**에서 확인하실 수 있습니다.

초대 메일의 링크로 설치하시면 됩니다. **"출처를 알 수 없는 앱" 경고**가 뜨면
허용해 주세요 — 스토어를 거치지 않은 테스트 빌드라 정상입니다.

---

### 이번에는 명함을 지우실 필요 없습니다

지난 빌드에서 등록하신 명함·사진은 **그대로 두고** 이어서 쓰시면 됩니다.
이번 변경은 기존 데이터와 호환되는 것을 저희 기기에서 확인했습니다
(재설치 복원 왕복 포함).

### 이번 배포에서 달라진 것

지난 빌드(8) 이후 고친 것들입니다. **여기 적힌 대로 안 되면 그게 바로 제보
대상입니다.**

#### 촬영·자르기 — 가장 많이 바뀌었습니다

- **촬영 가이드가 모서리 표식으로** 바뀌었습니다 — 이제 명함을 **꽉 채우지
  않아도** 됩니다. 대충 대면 자동으로 테두리를 찾습니다.
- **갤러리 사진도 자르기·자동 인식**이 됩니다. 사진을 불러오면 자르기 화면이
  뜨고, [자동 인식]이 명함 테두리를 찾아 줍니다(못 찾으면 그렇다고 말합니다).
- **회전이 누르는 즉시** 돌아갑니다. **반시계 버튼**도 생겼습니다.
- **갤러리에서 2장(앞·뒷면) 선택**과 **이어찍기**(앞면 찍고 [뒷면 이어 찍기])가
  됩니다.
- 자동 촬영이 헛돌면 **수동 촬영으로 전환**할 수 있습니다.

#### 명함 화면

- **편집 화면 상단에 명함 사진이 크게** 보입니다. 사진을 누르면 **전체화면
  확대**(두 손가락 확대, 앞·뒤 좌우 넘김)가 됩니다.
- **명함지갑 정렬**이 생겼습니다 — 최근 등록·이름·회사명·소통일·가까운
  거리순.
- 명함 상세 화면이 정리됐습니다 — 전화 띠 대신 **줄마다 연락 아이콘**, 닫기와
  편집이 같은 모양.
- **필수 입력이 현실에 맞게** 바뀌었습니다: 전화는 **휴대폰 또는 사무실 중
  하나**면 됩니다. 명함에 없는 값을 억지로 채우실 필요 없습니다.

#### 명함 인식 (자동 채움)

- **이름과 회사가 서로 뒤바뀌던 경우**(기관 이름이 위에 크게 있는 명함)를
  고쳤습니다.
- **회사명에 영문이 병기**된 명함(`케이스랩 K.ACE LAB`)은 한글만 깔끔하게
  들어갑니다.
- **괄호로 된 주소 줄**이 상세주소로 붙습니다.
- 이름을 확신하지 못하면 **엉뚱한 값 대신 빈칸**으로 둡니다 — 빈칸이면 직접
  입력해 주세요.

#### 지도·주변

- ⭐ **주변 인맥에 사람이 훨씬 많이 뜹니다.** 명함 주소를 지도 위 위치로
  바꾸는 방식을 **행정안전부 주소 API**로 바꿨습니다. 저희 기기에서는 위치가
  없던 명함 **70장이 전부 채워졌습니다(0장)**.
  - 앱을 켜면 **"인맥 위치를 준비하고 있어요"** 안내가 잠깐 뜹니다. 한 번에
    30장씩 처리하므로 명함이 많으면 **앱을 몇 번 껐다 켜야** 다 채워집니다.
  - 안 채워지는 명함이 남으면 **설정 → 명함 인식 진단**에서 몇 장이
    남았는지 보실 수 있습니다.
- 홈의 지도 카드가 **실제 데이터 기반 그림 지도**로 바뀌었습니다.
- **같은 건물 여러 명은 숫자 마커**로 묶이고, 누르면 명단이 올라옵니다.
- 지도로 보기에서 핀이 상단에 몰리던 것을 고쳤습니다 — 화면 가운데에
  잡힙니다.
- 지갑·주변 목록의 **상단(검색·정렬)이 고정**되고 내용만 스크롤됩니다.

#### 앱 전체

- **뒤로가기로 앱이 종료됩니다.** 제보해 주신 *"창만 닫히고 강제 종료해야
  하는"* 문제입니다.
  - 명함·설정 탭에서 뒤로가기 → **주변 탭으로** 돌아갑니다
  - 주변 탭에서 뒤로가기 → **"한 번 더 누르면 종료됩니다"** 안내가 뜨고,
    2초 안에 다시 누르면 **종료**됩니다
- 연락 후 "연락 어땠어요?"의 선택지가 `좋음 / 보통 / **아쉬움**`으로
  바뀌었습니다(전에는 "없음"이라 무슨 뜻인지 모호했습니다).

#### 로그인

- **카카오·네이버 로그인**이 생겼습니다. 네이버는 테스터 아이디를 미리
  등록해 두었으니 그대로 쓰실 수 있습니다.
- 카카오·네이버로 가입하셔도 **AI 기능이 정상 동작**합니다(전에는 막혀
  있었습니다).
- 카카오·네이버 계정도 **설정 → 계정 삭제**가 됩니다.

### 🎯 중점적으로 봐 주실 것 (우선순위 순)

#### 1순위 — 명함 등록이 실제로 쓸 만한가

**가장 중요합니다.** 이게 안 되면 나머지는 의미가 없습니다.

- 카메라로 명함을 찍었을 때 **이름·회사·직함·전화·이메일·주소가 제대로
  들어가는지**
- 특히 **주소**를 잘 읽는지 (주변 인맥 기능이 주소에 달려 있습니다)
- 세로형 명함, 영문 명함, 로고가 큰 명함 등 **다양한 형태로** 시도해 주세요
- 잘못 읽은 명함이 있으면 **그 명함 사진과 함께** 알려주시면 큰 도움이 됩니다
- **새로 생긴 것들도 눌러 봐 주세요**: 모서리 가이드로 대충 대고 찍기,
  갤러리 불러와 자동 인식·회전, 편집에서 사진 확대, 지갑 정렬

#### 2순위 — AI 대화 가이드가 쓸 만한가

⚠️ **두 가지를 갈라서 봐 주세요.** 저희가 고친 것과 아직 못 고친 것이 다릅니다.

**(가) 매번 다른 말이 나오는가** — 이건 이번에 고쳤습니다

- **"다시 만들기"를 여러 번** 눌러 보세요
- 누를 때마다 **문장 3개가 전부 달라지는지**
- ⚠️ 같은 말이 또 나오면 **고친 것이 안 먹은 것**이니 꼭 알려주세요

**(나) 그 문장이 쓸 만한가** — 이건 아직 손대지 않았습니다

- 실제로 **보낼 만한 수준인지**
- 어색하다면 **어떤 점이** 어색한지 (딱딱함 / 뻔함 / 사실과 안 맞음)
- 📌 *"매번 다르긴 한데 셋 다 별로다"* 같은 답이 저희에게 가장 쓸모 있습니다

**(다) 그 밖**

- 소통 기록을 넣었을 때와 안 넣었을 때 **결과가 달라지는지**
- 문자·카톡·메일로 보낼 때 **내용이 제대로 담기는지**

#### 3순위 — 주변 인맥이 맞게 뜨는가

⭐ **이번에 가장 크게 바뀐 곳입니다.** 위치를 찾는 방식을 통째로 바꿨습니다.

- **뜨는 사람 수가 늘었는지** — 전에 "주변에 아무도 없다"였다면 특히
- **위치가 엉뚱한 사람이 있는지** ⚠️ 이게 가장 중요합니다. 엉뚱한 위치는
  없는 것보다 나쁩니다 — 화면에는 정상으로 보이고 지도를 열어야 틀린 것이
  보입니다. 이상한 곳에 찍힌 명함이 있으면 **그 명함의 주소와 함께** 알려
  주세요
- 실제로 가까이 있는 사람이 뜨는지, **거리 표시가 맞는지**
- 감지 반경(500m~5km)을 바꿨을 때 목록이 달라지는지
- **지도에서 크게 보기**로 위치가 맞게 찍히는지

#### 4순위 — 쓰다가 불편하거나 이상한 곳

- 버튼을 눌렀는데 **아무 일도 안 일어나는** 곳
- 글자가 잘리거나 겹치는 곳
- **"이건 왜 이렇게 되지?"** 싶은 모든 순간

### 지금은 안 되는 기능 (결함이 아닙니다)

제보 전에 한 번 확인해 주세요.

- **지도가 해외 지도**라 한글 지번·건물 이름이 성깁니다 — 국내 지도 연동 준비 중
- **Gmail에서 메일 가져오기 없음**
- **통화·문자 기록을 자동으로 가져오지 않습니다** — 남기고 싶은 내용만 직접
  적거나 붙여넣는 방식입니다. 의도된 설계입니다
- **백그라운드 알림 없음** — 앱을 열었을 때 주변 인맥을 보여줍니다
- **AI는 하루 20회**까지 (테스트 기간 값 — 충전형 전환 뒤에는 하루 한도가 없어지고 **충전 잔액**이 상한이 된다)
- **명함 사진은 이 기기에만 저장됩니다** — 서버에 백업되지 않습니다. 그래서
  명함을 지우거나 앱을 지우면 사진은 복원되지 않습니다(명함의 글자 정보는
  서버에 백업되어 복원됩니다)
- **앱을 지웠다 다시 깔면 사진 한도 계산이 0으로 돌아갑니다** — 알려진 결함이고
  아직 안 고쳤습니다. 지금은 사진 서버 백업 자체가 꺼져 있어 테스트에는 영향이
  없습니다

### ⚠️ 개인정보 관련 부탁

이 앱은 **다른 사람(명함 주인)의 개인정보**를 다룹니다.

- 입력한 정보는 **실제 서버에 저장**됩니다
- **테스트가 끝나면 설정 → 계정 삭제(회원 탈퇴)** 로 정리해 주세요. 계정과

```
[무엇을 하려다] 명함 등록에서 카메라로 찍었는데

[기대한 것] 주소가 자동으로 채워질 줄 알았음

```

**앱 버전 값을 꼭 함께** 적어 주세요. 어느 빌드에서 생긴 문제인지 바로 찾을
수 있습니다. 화면 캡처가 있으면 더 좋습니다.

### 💰 값에 대해 여쭙습니다 (이번에만)

앞으로 **AI 대화 가이드**를 유료로 바꿀지 검토하고 있습니다. 명함 등록·주변 인맥
같은 기능은 그대로 무료입니다.

⚠️ **정답이 없는 질문입니다.** 저희가 정한 값이 없어서 여쭙는 것이니, **느낀 그대로**
답해 주시면 됩니다. *"안 낼 것 같다"*도 그대로 좋은 답입니다.

1. **AI 대화 가이드를 한 번 쓰고 나서, 그게 얼마짜리라고 느끼셨습니까?**
   (0원이라고 느끼셨다면 그렇게 적어 주세요)

2. **30회에 1,000원이면 어떻습니까?** (회당 33원꼴, 충전분은 매달 사라지지 않습니다)
   비싸다 / 적당하다 / 싸다 — 그리고 **왜** 그렇게 느끼셨는지 한 줄

3. **처음 가입할 때 무료로 몇 회쯤 줘야 "써 볼 만하다"고 느끼시겠습니까?**

4. **돈을 낸다면 어느 쪽이 낫습니까?**
   충전(쓴 만큼 차감) / 월 구독 / 둘 다 싫다

## 배포하는 사람이 확인할 것 (테스터에게 보내지 않는 부분)

1. **release 빌드인지** — debug에는 로그인 화면에 "로그인 건너뛰기" 버튼이
   그대로 보인다.
2. **배포 후 관리자 콘솔에 로그인 이메일 등록**
   (https://connection-sense-admin.web.app → 테스터 관리). 안 하면 App Check에
   막혀 AI가 전부 실패한다. **초대 이메일과 로그인 이메일이 다를 수 있다.**
3. **"지금 안 되는 기능" 목록이 최신인지** — 이 목록이 낡으면 정상 동작을
   결함으로 제보받아 서로 시간을 버린다.
4. 위 안내문의 **앱 버전 예시 값**을 이번 빌드 해시로 교체.
5. **"이번 배포에서 달라진 것"이 이번 빌드 내용인지** — 지난 배포분이 남아
   있으면 테스터가 이미 본 것을 또 확인한다.
6. **"먼저 해 주실 일"(초기화)이 이번 배포에도 해당하는지** — 해당 없으면
   그 절을 지운다. 남겨 두면 테스터가 매번 명함을 지운다.
