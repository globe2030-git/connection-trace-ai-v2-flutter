# 릴리스 체크리스트

스토어 제출 전과 테스터 배포 전에 밟는 순서. 지금까지 이 절차가
[`backlog.md`](./backlog.md) 산문에 흩어져 있어, 매번 기억에 의존했다.

**전제**: [`CLAUDE.md`](../../CLAUDE.md)의 작업 규약과
[`tool/README.md`](../../tool/README.md)의 검증 도구를 먼저 읽을 것.

---

## 0. 왜 이 순서인가

이 프로젝트에서 실제로 터진 결함은 대부분 **자동 검사가 원리상 못 잡는
자리**에 있었다. 그래서 아래 단계는 "덮는 범위"가 서로 다르게 짜여 있다.

| 단계 | 덮는 것 | 못 덮는 것 |
|---|---|---|
| 자동 검사 | 컴파일·정적분석·순수 로직 | 화면, 저장소 실물, 기기 |
| 실물 점검 | 서버·기기 저장소의 실제 내용 | 화면, 사용자 흐름 |
| 기기 확인 | 화면·조작·크래시 | 저장소 내부, 서버 권한 |
| 사람 눈 | 위 전부의 빈틈 | — |

**"테스트가 통과했다 = 동작한다"가 아니다.** 서버에 개인정보가 평문으로
남아 있던 것도, 좌표 재계산이 죽어 있던 것도, 그때 테스트는 전부 초록불이었다.

## 1. 코드 (자동)

```bash
flutter analyze     # error·warning 0건 (info는 기존 잔재라 허용)
flutter test
```

브랜치에 push하면 CI가 같은 것을 자동으로 돌린다. **PR 검사가 통과해야 병합**한다.

보안에 닿는 변경(인증·암호화·규칙·개인정보 전송)이 있으면 **머지 전에**
`/security-review`를 돌린다. 커밋을 마친 뒤에 돌리면 대상 diff가 0이라 아무것도
안 나온다.

## 2. 실물 점검 (저장·암호화·마이그레이션을 건드렸을 때 필수)

```bash
python3 test/firestore_rules/verify_rules.py    # 규칙을 고쳤다면 배포 전에
python3 tool/verify_server_privacy.py           # 서버: 평문 0건, 좌표 0건
python3 tool/verify_device_local.py             # 기기: 암호문 + 좌표 채워짐
```

서버와 기기는 **짝으로** 본다. 설계 의도가 "좌표는 기기에만, 서버에는 없음"
이라 한쪽만 보면 절반만 확인한 것이다.

⚠️ 기기 점검은 **디버그 빌드**에서만 된다(`run-as` 제약). 릴리스로 테스트
중이라면 잠시 디버그로 바꿔 확인하고 되돌린다.

## 3. 빌드

```bash
tool/build_app.sh apk release     # Android 테스터 배포용
tool/build_app.sh ios release     # iOS
```

`flutter build`를 직접 쓰지 말 것 — 커밋 해시가 안 들어간다.

- 테스터·스토어 배포는 **반드시 release**. debug 빌드에는 로그인 화면에
  "로그인 건너뛰기" 버튼이 그대로 보인다.
- 빌드 후 **설정 → 앱 버전**에서 방금 만든 커밋 해시가 보이는지 확인한다.
  `+수정중`이 붙어 있으면 커밋되지 않은 코드가 섞인 빌드다.

## 4. 기기 확인

**Android** (갤럭시 Z 폴드 — 접힌 상태에서는 `adb` 조작이 안 먹으니 펴 둘 것)

- [ ] 로그인 → 명함 등록(촬영·갤러리 둘 다, 한글 인식 확인)
- [ ] **주소 찾기 → 검색 → 목록에서 선택** — 목록에 보인 문장이 그대로
      들어오는지, 저장 시 변환을 다시 묻지 않는지
- [ ] 주변 탭 — 등록한 인맥에 거리가 뜨는지
- [ ] 설정 → 약관 및 정책 — 문서가 열리는지
- [ ] **앱 삭제 → 재설치 → 로그인** — 명함이 복원되고 거리가 다시 뜨는지,
      설정에 이전 로그인 정보가 남아 있지 않은지

**iOS** — 스크린샷 도구가 없어 **사람이 직접 폰을 잡고 봐야 한다.** 화면 확인을
건너뛰면 iOS 시각 결함은 출시 후 제보로만 발견된다.

- [ ] 위 Android 항목 전부
- [ ] 색·폰트·여백이 Android와 같아 보이는지
