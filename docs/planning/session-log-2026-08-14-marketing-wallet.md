## C. 준비 방향 (어떻게 가는가)

1. **순서**: 출시 준비(0단계) → **소규모 리텐션 파일럿**(리텐션 30%+ / AI 품질
   4.0+ 게이트) → 통과 시 6개월 그로스 → **과금 부분 테스트·배포** → 스토어 출시.
   *상품성 미검증 상태에서 유입에 돈을 쏟지 않는다 — 파일럿이 그로스보다 먼저.*
2. **과금 엔진은 완성·검증·고정 상태로 대기**한다. 지금 병합·배포하지 않는 이유:
   테스터가 실제 Firebase 백엔드를 써서, main 병합분이 나중에 `firebase deploy`에
   딸려 나가면 테스터 크레딧을 건드릴 위험. 출시 근접 시 사용자 승인과 함께 켠다.
3. **성장은 회차 증정 3엔진**(리퍼럴·커뮤니티 시딩·지점 챔피언) — 현금이 아니라
   회차라 원가 극소. 프로모션은 할인이 아니라 증정.
4. **모든 배포·정책·병합·스토어 출시의 go/no-go는 사용자 최종 결정**(최상위 지침).
