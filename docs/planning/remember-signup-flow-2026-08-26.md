# 리멤버 가입 흐름 실물 관찰 — 우리와 갈리는 다섯 (2026-08-26)

**무엇을 봤나**: 리멤버 **웹**(`career.rememberapp.co.kr`) 회원가입 흐름 화면 기록
93초. 사용자가 직접 녹화해 전달.

> ⚠️ **개인정보는 이 문서에 옮기지 않았다.** 녹화에는 실제 전화번호·이름·이메일이
> 찍혀 있다. 화면 구조와 **문구만** 적는다. 뽑아 둔 프레임도 개인정보가 있는 것은
> 지웠다(약관 모달 두 장만 남김 — 거기엔 개인정보가 없다).
>
> ⚠️ **이것은 관찰이지 추천이 아니다.** 리멤버가 하는 방식이 곧 적법하거나 최선이라는
> 뜻이 아니다. 우리 판단의 근거는 법무 회신(추가 473)이고, 이 문서는 **업계 실물이
> 어디에 있는지**를 알려 줄 뿐이다.

---

## 0. 흐름 전체

```
회원가입   카카오 / 네이버 / 구글 / 이메일  (넷)
   ↓
약관 모달  만14세(필수) · 이용약관(필수) · 개인정보(선택) · 광고 수신(선택)
   ↓
이메일 + 비밀번호
   ↓
본인 확인  이름 입력 → 휴대폰 번호 → 인증번호 6자리(3분 타이머·재전송)
   ↓
🚨 "이미 리멤버 계정이 있습니다"   ← 번호로 기존 계정을 찾아 보여준다
```

---

## 1. ✅ "광고성 정보"라고 정확히 부른다 — 우리 조사와 일치

리멤버 문구 그대로:

```
(선택) 광고성 정보 수신동의
       스카우트 제안 등 맞춤 혜택/정보를 받을 수 있어요
```

📌 **완곡어를 안 쓴다.** 우리 초안의 *"새 소식을 받아보시겠어요?"*가 왜 안 되는지를
업계 실물이 확인해 준다(법률 조사 추가 457 — 안내서 p.12는 *"마케팅 동의"*조차 금지).

⭐ 그리고 **혜택은 부제에서 말하고 제목은 정확하게 쓴다.** 우리가 *"광고성 정보 수신
동의"*를 제목으로 두고 설명에서 *"새 기능 소식, 이벤트·할인 안내"*를 말한 것과 같은
구조다.

---

## 2. 🚨 "본인 확인"이라 부르지만 실제로는 휴대폰 인증이다

화면 제목은 **"본인 확인을 위해 아래 정보를 입력해주세요"**인데, 실제로 받는 것은:

| 무엇 | 어떻게 |
|---|---|
| 이름 | **이용자가 직접 입력**(예: 홍길동 자리표시자) |
| 휴대폰 번호 | 국가코드 `+82` + 번호 → **인증번호 6자리** |

**없는 것**: 통신사 선택 · 주민등록번호 앞자리 · PASS 앱 연동 · 생년월일.

→ **본인확인기관(NICE·KCB 등, 건당 40원 안팎)을 거치지 않는다.**

⭐ **사용자가 2026-08-25에 정정한 *"본인인증이 아니라 핸드폰인증"*이 리멤버 실물과
정확히 같다**(추가 462 개정). 우리가 6.5원짜리를 고른 것이 업계에서 벗어난 선택이
아니다.

### 📌 여기서 따라오는 것 — 리멤버도 만 14세를 검증하지 못한다

이름이 자기 입력이고 생년월일을 아예 안 받으므로, **`(필수) 만 14세 이상입니다`
체크는 자기 신고다.** 우리와 같다.

⚠️ 이것을 *"그러니 우리도 괜찮다"*로 읽으면 안 된다. 법무 회신(추가 473 Q10-④)이
관행에 대해 답한 그대로다 — **관행은 적법성의 근거가 아니라 집행 우선순위·과실
판단·시정 기회를 바꿀 뿐이다.** 다만 **우리만 뒤처진 것은 아니라는 사실**은
확인됐다.

---

## 3. 「모두 동의합니다」가 있다 — 우리는 없다

**기본값은 전부 꺼진 상태로 시작한다**(회색 체크). ✅ 이건 우리와 같고, 법이 요구하는
바다.

**「모두 동의합니다」를 한 번 누르면 넷이 전부 켜진다 — 광고 수신 동의까지.**

| | 리멤버 | 우리(추가 472) |
|---|---|---|
| 전체 동의 버튼 | **있음** | 없음 |
| 매체 구분 | **없음** (광고 하나) | 이메일 / 앱 알림 **따로** |
| 개인정보 이용 동의 | 다른 항목과 **나란히** | 매체의 **전제**로 잠금 |
| 항목 수 | 4 (필수 2 + 선택 2) | 3 (전부 선택) |

⚠️ **우리 쪽이 더 엄격하다.** 법무 회신이 *"개수를 문제 삼는 문언이 조문 어디에도
없다 — 뭉뚱그린 동의가 위험하지 나눈 동의가 위험하지 않다"*고 했으므로 우리 방식이
안전한 쪽이다.

📌 **대신 가입 마찰은 우리가 크다.** 리멤버는 한 번 눌러 끝나고, 우리는 최소 두 번
누른다(전제 → 매체). 이건 위험과 마찰의 맞바꿈이고, **바꿀지 말지는 결정 사항**이다.

### 전체 동의 버튼을 우리도 넣을 것인가 — 정하지 않았다

넣는다면 ⚠️ **선택 항목까지 한 번에 켜지는 형태**가 된다. 자유로운 의사 결정
(시행령 §17①1호)과의 관계를 리갈에 물어야 한다. **지금은 안 넣은 상태이고, 넣자는
제안이 아니다.**

---

## 4. ⭐ 이중등록 방지의 실물 — 우리가 아직 못 정한 부분이다

번호 인증이 끝나자 **가입을 계속하지 않고** 이 화면이 뜬다.

```
이미 리멤버 계정이 있습니다
+82 10-****-**** 번호로 가입한 계정이 있습니다. 아래 계정으로 로그인해 주세요

  ✉  gl*******@ic****.com          2015-04-29 가입
  ＋  새 계정 만들기

  로그인할 수 없나요? 문의하기
```

**배울 점 넷** — 계정 설계(I안)를 맡은 세션에 그대로 넘길 값이 있다.

| 무엇 | 왜 |
|---|---|
| **이메일을 마스킹**해 보여준다 | 남의 번호를 넣어 본 사람에게 남의 이메일을 통째로 보여주지 않는다 |
| **가입일**을 함께 보여준다 | *"이게 내 계정인가"*를 판단할 단서. 이메일만으로는 기억 못 한다 |
| **「새 계정 만들기」를 막지 않는다** | 강제 병합이 아니라 **선택지를 준다** |
| **「로그인할 수 없나요? 문의하기」** | **막다른 길을 만들지 않는다** |

🚨 **네 번째가 특히 중요하다.** 번호는 있는데 그 계정의 이메일·비밀번호를 모르면
이용자는 갇힌다. 리멤버는 그 자리에 사람에게 닿는 길을 뒀다.

⚠️ 그리고 이 화면은 **번호 재사용 위험과도 맞닿는다**(추가 462 개정). 해지된 번호는
90일 뒤 남에게 배정되는데, 그 사람이 인증하면 **전 주인의 계정이 이 화면에 뜬다.**
리멤버는 마스킹으로 노출을 줄이고 **자동 로그인은 시키지 않는 것**으로 다룬다 —
로그인은 여전히 그 계정의 자격증명을 요구한다.

---

## 5. 광고 동의를 가입 흐름 안에서 받는다 — 우리는 못 그렇게 한다

리멤버는 약관 모달에 광고 동의를 **함께** 넣었다. 우리는 **로그인 직후 별도 화면**이다.

⚠️ **우리가 다르게 한 것은 취향이 아니라 구조 때문이다.**

```
리멤버   가입과 로그인이 갈라져 있다  → 가입 흐름 안에 넣을 자리가 있다
우리     로그인 = 가입 (SNS 하나뿐)   → 그 자리가 없다.
                                    로그인 화면에 넣으면 기존 이용자가 매번 본다
```

그래서 **"광고 수신 동의 기록이 없는 계정에게 로그인 직후 1회"**로 잡았다(추가 472).

📌 **계정 방식이 리멤버식으로 바뀌면 이 전제가 달라진다.** 가입 흐름이 생기면 그
안에 넣을 수 있고, 그때는 배치를 다시 볼 값이 있다.

---

## 6. 정리 — 무엇을 바꿀 값이 있나

| | 판단 |
|---|---|
| 광고를 *"광고성 정보"*라고 부르기 | ✅ **이미 같다.** 바꿀 것 없음 |
| 휴대폰 인증(본인확인 아님) | ✅ **이미 같다.** 우리 선택이 업계와 어긋나지 않음 |
| 만 14세 자기 신고 | ✅ 같다. ⚠️ 다만 관행은 적법성의 근거가 아니다 |
| **전체 동의 버튼** | ❔ **정하지 않음** — 넣으면 마찰이 줄고 위험이 는다. 리갈 질문 감 |
| **매체를 나눌 것인가** | 우리가 나눔. 법무 회신상 안전한 쪽이라 **유지** |
| **이중등록 화면** | 🚨 **우리에게 없다.** 계정 설계 세션에 넘긴다 |
| 광고 동의의 위치 | 지금은 별도 화면이 맞다. **계정 방식이 바뀌면 다시 본다** |

## 확인하지 못한 것

- **앱(iOS·Android) 가입 흐름** — 이 녹화는 **웹**이다. 앱은 다를 수 있다
- 카카오·네이버·구글로 가입했을 때의 흐름 — 녹화는 **이메일 경로**만 탔다
- 약관 링크(`>`)를 눌렀을 때 나오는 전문
- 인증 문자가 어떤 발신번호로 오는지, 알림톡인지 SMS인지
- **광고 동의를 끈 채로 진행했을 때** 뒤 흐름이 달라지는지

⚠️ **위 항목들을 짐작으로 메우지 않았다.** 필요하면 다시 녹화를 받아야 한다.
