#### ⚠️ 다시 찍지 않고 재 보려 했으나 — **막혔다**

*"내 손으로 하지 않아도 정답지로 해볼 수 있지?"* 라는 물음에 따라, 저장된

```
원본 82장 → 검출로 자름 7장 · ⚠️ 못 찾아 원본 그대로 75장
```

**비교가 성립하지 않는다.** 검출기는 **카메라 미리보기 화면**에 맞춰져 있어
저장된 사진에서는 사각형을 못 찾는다.

⚠️ **기기 동작을 뒤집는 결과가 아니다.** 폴드·아이폰 두 번 다 잘 잡았다

⚠️ **저장 사진용으로 검출을 손보지 않기로 했다**(사용자 결정). 그러면 **앱과

#### ⭐ 실물로 두 방식을 재 봤다 — **인식률은 같다**

폴드로 **같은 명함 13장을 두 번씩** 찍어 쟀다(고정 가이드 → B′ 검출).

```

```

**121칸 중 2칸 차이 — 사실상 같다.** 착수 전에 정한 *"같음 → 그대로 두고
기록한다"*에 해당한다.

##### 📌 갈린 6칸은 전부 **OCR 오독**이었다 — 자르기와 무관하다

```
최태응 ↔ 최태웅              B′가 맞음
AI 아키텍처팀 ↔ A아키텍처팀    B′가 틀림
```

**같은 명함을 두 번 찍으면 글자가 조금씩 다르게 읽힌다.** 어느 방식이 나은
