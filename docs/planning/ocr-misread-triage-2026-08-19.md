## 2. 다시 가른 방법

정답과 파서 결과가 다른 장마다, **원문(OCR이 읽은 글자 전체)을 함께 봤다.**
280과 다른 점은 **"통째로 없으면 오독"에서 멈추지 않고 조각까지 본 것**이다.

```
정답 == 파서값                      → 일치 (세지 않음)
정답이 원문에 통째로 있다           → 읽었는데 못 고름   (파서 문제)
정답 조각이 원문에 전부 있다        → 조각은 다 읽음     (표기·조합 문제)
정답 조각이 일부만 있다             → 혼합
정답 조각이 하나도 없다             → 진짜 오독 후보     (인식 문제)
파서값이 비었고 원문엔 있다         → 미검출             (파서 문제)
파서값이 있고 정답이 비었다         → 오검출             (파서 문제)
```

비교는 유니코드 정규화(NFKC) 후 **모든 공백을 지우고** 한다.

⚠️ **재현 방법**: 이 분해는 저장소 코드가 아니라 **일회성 스크립트**로 했다.
규칙이 위에 적혀 있으니 다시 짜면 된다. 입력은 둘이다.

```
scan_result.tsv   앱이 내보낸 인식 결과 (원문 칸 필요)
ocr_truth.tsv     검수 도구가 만든 정답지
```

## 4. 그래서 R-03을 줄이자 — **이메일 전용 라틴 2차 패스**

전면 다중 패스는 **99장 재촬영 + 두 결과 합치기**인데, 얻는 것이 최대 19건이다.
대신 이렇게 줄인다.

> **이메일 칸이 비었거나 형식에 안 맞을 때만, 라틴 인식기로 한 번 더 읽는다.**

| 왜 이 칸인가 | |
|---|---|
| 판정이 확실하다 | 이메일은 **정규식으로 검증된다.** 라틴 결과가 형식에 맞으면 채택, 아니면 버린다 — 다중 패스에서 가장 어려운 "합치기"가 **이 칸에서는 없다** |
| 비용이 작다 | 이메일이 이상할 때만 도니 매번 두 번 읽지 않는다 |
| 표본이 작다 | 이메일이 틀린 **6장**만 다시 찍으면 이득을 잴 수 있다 |

📌 **재료는 이미 앱에 있다.** iOS는 `GoogleMLKit/TextRecognition`(라틴)과
`TextRecognitionKorean`이 둘 다 링크돼 있다(`ios/Podfile.lock`). 안드로이드에
라틴 모델이 함께 들어오는지는 **아직 확인 안 했다.**

⚠️ `ios/Podfile:41`의 경고를 함께 볼 것 — 팟을 제대로 안 넣으면 **Dart에서
스크립트를 지정해도 조용히 라틴 인식기로 떨어진다.** 다중 패스를 만들 때
**두 결과가 실제로 다른지부터** 확인해야 한다. 안 그러면 *"두 번 읽었는데
사실은 같은 모델로 두 번"*이 되고, **결과가 그럴듯해서 티가 안 난다.**

## 6. ✅ 정해졌다 (2026-08-19 사용자 확정)

추가 286이 물어 둔 셋에 답이 나왔다.

| | 물음 | **결정** |
|---|---|---|
| **가** | 직함에 부서를 넣나 | ❌ **안 넣는다. 부서는 별도 필드로 뺀다** |
| **나** | 구분자 `\|`를 쓰나 | ❌ **안 쓴다** — 가로 자동 해소(아래) |
| **다** | 영문을 넣나 | **직함이면 넣고 회사명이면 뺀다** |

### 나는 가로 저절로 풀렸다

`\|`는 **명함이 아니라 정답지** 얘기였다. 검수자가 한 칸에 둘을 몰아 적으며 쓴
기호다.

```
정답지   부장 | 스포츠기획팀        ← 직함 + 부서를 한 칸에
원문     … 부장 스포츠기획팀 …      ← ⚠️ '|' 가 없다
```

**부서가 별도 칸으로 가면 한 칸에 둘을 몰아 적을 이유가 없다.** 따로 정할 것이
없어진다.

### 다 — "영문이냐"가 아니라 "직함이냐"

```
대표 CEO                              ← 영문 직함 병기 → 넣는다
연구소장 Green IT Korea Plus Newness  ← 뒤는 회사명   → 뺀다
```

추가 286의 시도 ②가 **−5장**으로 실패한 이유가 이것이다. 영문 꼬리를 **일괄로**
지웠기 때문에, 병기까지 함께 날아갔다.

⚠️ **착수 전에 이 문서의 숫자가 바뀐다는 것을 알아 둘 것.** 직함 "조각은 다
읽음" 13건 중 **6건이 "정답이 부서까지 포함"**인데, 부서 칸이 생기면 그 6건은
직함에서 빠져 부서로 간다. **파서를 고치기 전에 정답지부터 다시 정리해야 한다.**
