폴백한다"* 라고 적고 있는데, **그것은 `flutter build` 를 직접 쓸 때의 이야기다.**
`tool/build_app.sh:63~87` 이 배포용 산출물 진입점에서 **중단**시킨다(스크립트

아니라 「중단」이다"*).

📌 **그래서 위험은 「모르고 debug 로 나가는 것」이 아니라 「빌드가 안 되는 것」이다.**
⚠️ **다만 `flutter build` 를 직접 쓰면 여전히 조용히 debug 로 나간다** — 규약의
경고는 그대로 유효하다.

⭐ **「debug 가 아니다」로 그치지 않고 「업로드 키와 같다」까지 봤다.** DN 만 보면
*"`CN=Android Debug` 가 아니니 됐다"* 로 끝나는데, 그것은 **다른 키로 서명된

> 🚨 **여기서 도구 함정이 하나 나왔다 — `keytool` 이 한글 로캘에서 죽는다.**
>
> ```
> keytool -list -v -keystore … -alias …
>   → 별칭 이름: upload / 생성 날짜 / 항목 유형까지 찍고
>     keytool 오류: java.util.IllegalFormatConversionException: d != java.lang.String
> ```
>
> **인증서를 찍는 자리에서만** 터진다. 앞부분이 정상으로 나와서 **「키스토어가
> 깨졌나」로 읽기 쉽다** — 키스토어는 멀쩡하다. **해결은 로캘을 영어로 주는 것:**
>
> ```bash
> keytool -J-Duser.language=en -J-Duser.country=US -list -v -keystore … -alias …
> ```
>
> 📌 **런북 §4 의 서명 확인 절차에 이 줄이 없다** — 다음 사람이 같은 자리에서
> 멈춘다. ⚠️ 이 저장소의 검증 도구는 대부분 `apksigner` 를 쓰는데, **키스토어
> 쪽 지문을 뽑는 것은 `keytool` 뿐이라** 대조를 하려면 반드시 걸린다.
