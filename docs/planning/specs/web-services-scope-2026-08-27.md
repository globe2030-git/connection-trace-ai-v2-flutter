## 1. 갱신 — 계정 기획(D)은 이미 결정났다, 단 "구현 완료"가 새 게이트다

`HANDOFF.md`(556행, 1050행)에서 확인:

```
계정 구조   ✅ I안(리멤버식) 확정 — 2026-08-25 사용자, 두 번 확인
           전화번호를 계정의 주인으로 삼는다
구현 목표   2026-09-15(방침 v2.x 시행 전까지)
배포일     미확정 — 알림톡 심사(10 영업일)·발송 대행사 계약 등 행정에 달림
```

⚠️ **이게 08-24 브리프의 전제를 하나 바꾼다.** 그 문서 3-5절은 "D가 아직
결정 안 났으니 로그인 화면 틀만 잡고 실제 인증 로직은 짜지 말라"고 했다.
지금은 **방향은 정해졌지만 아직 구현되지 않았다** — 그러므로 B·C의
로그인 배선이 기다리는 대상이 바뀐다.

```
08-24 시점    D "결정"을 기다림 (언제 날지 모름)
08-27 시점    D는 결정났고, **I안이 앱에 실제로 구현되는 것**을 기다림
             (목표 09-15, 배포일은 아직 미확정 — 즉 "언제 쓸 수 있게 되는지"는
              여전히 불확실하다. 기다리는 대상이 바뀌었을 뿐 대기 상태는 안 풀렸다)
```

📌 **왜 이게 중요한가**: "결정 대기"와 "구현 대기"는 다르다. 결정 대기는
사용자가 답 하나만 내면 그날 풀리지만, **구현 대기는 개발 완료 + 배포까지
걸려야 풀린다.** B·C의 로그인 연동은 **I안이 실제로 동작하는 웹 로그인
(전화번호 인증 기반)이 나온 뒤에** 붙일 수 있다 — 08-24 문서가 말한
"구글 팝업/카카오·네이버 커스텀토큰"이 아니라 **전화번호 인증 흐름**이
새 전제가 됐다는 뜻이다(구글 로그인 자체는 살아 있지만 "계정을 무엇으로
식별하나"의 기준이 이메일이 아니라 전화번호로 바뀌기 때문).

## 3. 그림으로 — 의존관계 (날짜 아님, 순서만)

```
① 홈페이지
   └─▶ (이미 게시됨) 커스텀 도메인만 사용자 결정 남음

법무 답(제3자 웹 표시·공용PC 캐시 위험) ── 아직 회신 없음(08-27 기준)
   └─▶ ② 웹 교정 도구 "구현" 착수 게이트 하나

계정 I안 구현(09-15 목표, 배포일 미확정)
   └─▶ 웹 로그인(전화번호 인증 기반) 연동
        └─▶ ② 웹 교정 도구 "구현" 착수 게이트 둘
        └─▶ ③ 웹 업로드·인식 (도달 못 함 — 아래에서 이미 막혀 있음)

사진 서버 백업 시행일 2026-09-15(방침 v2.2)
   └─▶ ②에서 "사진을 보며" 고치는 부분만 추가로 게이트(텍스트만 고치는
        것은 이미 서버에 필드가 있어 이 게이트와 무관, 08-24 브리프 3-3)

서버 인식(OCR) 채택 여부 ── "안정화 후 재논의"로 보류(사용자 기결정)
   └─▶ ③ 웹 업로드·인식 — 이 자체가 안 풀리는 한 ②가 다 풀려도 ③은 그대로 대기
```

**읽는 법**: ②는 게이트가 **셋**(법무·로그인·사진 시행일)이고, 셋 다
안 풀려도 **화면 설계까지는 지금 해도 된다.** ③은 ②의 화면을 재사용할
계획이지만 그 전에 서버 인식 자체가 막혀 있어 **논의할 근거가 없다.**

## 4. 무엇이 지금 착수 가능한가 (재확인)

- **① 홈페이지**: 이미 됐다. 남은 것은 마케팅 세션 산출물(`docs/marketing/
  landing-page-copy.md`)과 지금 배포된 `docs/site/`가 같은 내용인지 대조하는
  것 정도 — 다르면 최신화 필요.
- **② 웹 교정 도구**: **화면 설계·정적 프로토타입은 지금도 착수 가능**
  (08-24 브리프 4절에 이미 완성된 설계가 있다 — 목록 화면·교정 화면·용어
  대조표까지). **실제 데이터 연동(Firestore 읽기·로그인)은 게이트 셋 중
  하나라도 안 풀리면 착수 금지.**
- **③ 웹 업로드·인식**: 설계 메모만(②의 화면을 그대로 이어 쓴다는 것) —
  이미 08-24 브리프에 적혀 있고 더 보탤 게 없다.
- **④ 계정 기획**: 구현이 이미 다른 세션/작업에서 진행 중인 항목이라 이
  문서가 손대지 않는다.
