# 아이디어 — **검수 도구를 관리자 콘솔로** (기록만)

**사용자 지시**: *"채점기는 나중에 수동 입력을 위해서도 필요한 기능이니까.
활용가치가 있어. 아직 수동 입력을 생각하고 있지 않지만 관리자에 넣으면
좋겠다."*

**2026-08-17 · 착수 안 함. 기록만.**

---

## 1. 왜 이 말이 나왔나

오늘 이 도구가 **측정을 세 번 구했다.**

```
① 정답지 86행이 인식 결과 복사본이었다        (추가 280)
② 로고 표기가 장마다 달랐다                   (추가 278)
③ 팩스 칸이 비고 사무실에 팩스가 적혀 있었다   (추가 282)
```

📌 셋 다 **사람이 명함 사진을 보고 칸을 고쳐야** 풀렸다. 그리고 그 일을 하는
동안, 이 도구가 하는 일이 **"정답 만들기"가 아니라 "명함을 보고 칸을 채우기"**
라는 것이 드러났다. **그건 수동 입력과 같은 일이다.**

---

## 2. 지금 이 도구가 가진 것

| | |
|---|---|
| 사진과 칸을 **나란히** 본다 | 좌우 너비 조절, 회전, 원본 크기 |
| **원문 낱말을 눌러** 칸에 넣는다 | 타이핑을 거의 안 한다 |
| **인식값을 회색으로** 옆에 보여준다 | 누르면 그대로 정답이 된다 |
| **볼 것만 거르기**(추가 283) | 칸을 골라 *"그 칸이 빈 장"*만 훑는다 |
| **칸이 늘면 알린다**(추가 283) | 새 칸은 아무도 본 적이 없다 |
| **정답지 불러오기**(추가 284) | 내보낸 것을 되읽는다 |

⚠️ **이만한 것을 다시 만들 이유가 없다.** 수동 입력 화면을 새로 그리면 위
여섯을 처음부터 다시 만드는 셈이다.

---

## 3. ⚠️ 그런데 그대로 옮기면 안 된다 — **가장 큰 문제**

이 앱은 **명함을 계정별 열쇠로 암호화해 저장한다.** 서버에는 암호문만 올라가고
**우리도 못 읽는다.** 그것이 이 제품의 약속이다.

```
지금        내 손의 표본 103장 · 내 기기 · 로컬 HTML
관리자 콘솔  웹 · 로그인 · 서버
```

⚠️ **관리자 콘솔에 넣는다는 것이 "관리자가 사용자 명함을 본다"가 되면 안
된다.** 그건 기능 추가가 아니라 **제품의 약속을 깨는 일**이다.

### 그래서 선이 이렇다

| | |
|---|---|
| ✅ **우리 표본** 명함(103장 등) 검수 | 우리가 찍고 우리가 가진 것 |
| ✅ 인식 규칙을 고친 뒤 **정확도를 다시 재는** 자리 | |
| ❌ **사용자 명함을 관리자가 열람** | 암호화 설계상 불가능하고, 가능해져도 안 한다 |
| ❌ 사용자 대신 **관리자가 명함을 입력해 주는 것** | 위와 같다 |

📌 **"수동 입력"이 누구의 입력인지가 갈림길이다.** 사용자가 자기 앱에서 손으로
넣는 것이라면 그건 **앱 안의 화면**이지 관리자 콘솔이 아니다.

---

## 4. 그러면 어디에 값이 있나 — 두 갈래

### ㉮ 관리자 콘솔의 **인식 품질 도구**

```
관리자 로그인 → 표본 올리기 → 인식 돌리기 → 검수 → 정확도 표
```

지금은 이 흐름이 **기기·adb·로컬 HTML·손으로 옮긴 TSV**에 흩어져 있다.
⚠️ 오늘만 해도 그 사이에서 **검수 결과가 한 번 통째로 날아갔다**(추가 284).

**모으면 얻는 것**: 기기 없이 돌릴 수 있다 · 결과가 안 사라진다 ·
누가 언제 검수했는지 남는다.

### ㉯ 앱 안의 **손으로 고치기** 화면

사용자가 자기 명함을 고칠 때, 지금 이 도구가 가진 **"사진 보며 원문 낱말을
눌러 칸에 넣기"**가 그대로 쓸모 있다. ⚠️ **이건 관리자 콘솔이 아니라 앱이다.**

📌 **㉮와 ㉯는 다른 물건이다.** 코드를 나눠 쓸 수는 있어도 **한 화면으로 묶으면
안 된다** — 관리자 화면에 사용자 명함이 들어오는 길이 생긴다.

---

## 5. 하려면 무엇이 걸리나

| | |
|---|---|
| 지금 도구는 **한 파일짜리 HTML** | 저장이 브라우저에 붙어 있고 `file://`에서 막힌다(추가 284) |
| 이미지가 **로컬 폴더** | 웹으로 옮기면 어딘가에 올려야 한다 — ⚠️ **표본도 실존 인물의 명함이다** |
| 인식은 **기기에서** 돈다 | ML Kit이 기기 것이라, 서버에서 돌리려면 다른 인식기가 필요하다 |

⚠️ **마지막이 가장 크다.** 서버에서 다른 인식기로 재면 **기기에서 나오는 값과
다른 것을 재게 된다.** 그러면 지금까지의 숫자와 이어지지 않는다.
