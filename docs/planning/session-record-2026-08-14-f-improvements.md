## 완료한 것 — F 3건

### F-02 · 주소 없는 명함 등록 허용 ✅ (PR #146, 병합됨)

- **문제**: 명함에 주소가 없는 경우가 흔한데 등록 화면에서 주소가 필수라 저장
  자체가 막혔다.
- **한 일**: `add_card_modal_view.dart`에서 주소를 **선택 입력**으로 전환 —
  `_saveCard`의 빈 주소 차단과 필드 validator의 빈 값 거부 제거, 라벨
  `회사 주소 (도로명) *` → `회사 주소 (도로명)`. 빈 주소면 지오코딩 단계를
  건너뛴다(빈 문자열을 지오코더에 넘기면 "주소 못 찾음" 창이 잘못 뜸).
- **사용자 실기기 피드백 반영**: 침묵 저장 금지 — 빈 주소 저장 시 **1회 확인
  다이얼로그**("주소 없이 저장할까요? … 명함 뒷면에 주소가 있을 수 있어요 …
  '주변'에는 표시되지 않아요", 취소/그래도 저장). 기존 중복 전화번호 확인과
  같은 AlertDialog 패턴. 이름·회사·휴대폰·이메일은 그대로 필수.
- **검증**: analyze 신규 0, test 통과. 실기기에서 주소 비우고 저장→확인
  다이얼로그→그래도 저장→지갑 등록(위치-없음 아이콘), 취소→미저장·폼 유지,
  주소 채운 저장 정상까지 확인. 사용자도 실기기에서 동일 확인. 테스트 명함은
  검증 후 삭제.

### F-12 · 가까운 인맥 목록에 주소 표시 ✅ (PR #148, 병합됨)

- **문제**: '주변' 화면의 가까운 인맥 목록이 이름·직함·회사만 보여, "지금
  어디쯤 가까이 있는가"라는 화면 목적에 비해 정보가 부족했다. (F-12의 검색어
  지우기 X 버튼은 이전에 완료돼 있었음)
- **한 일**: `radar_view.dart`의 `_NearbyContactTile` 회사명 줄 아래에 주소
  한 줄(위치 핀 아이콘 + 도로명). 주소가 비면 줄 자체를 숨긴다.
- **검증**: analyze 0, test 통과. 실기기에서 감지 반경을 '제한 없음'으로 두어
  좌표 있는 인맥을 띄우고, 각 타일에 `📍 도로명 주소`가 표시되는 것 확인
  (예: 경기 용인시 기흥구 신갈로 60). 확인 후 반경을 원래 값(1km)으로 되돌림.

### F-06 · 명함 선택 삭제 모드(발견성 + 일괄) ✅ (PR #150, 검증 완료·병합 대기)

- **문제**: 삭제가 왼쪽 스와이프뿐이라 발견성이 낮고, 여러 장을 한 번에 지울
  방법이 없었다.
- **과거 결정과의 충돌**: "명함 목록에 삭제 버튼을 두지 않는다"(2026-08-10,
  빨간 휴지통이 산만해서)는 결정이 있었다. **사용자와 방식을 정한 뒤 선택
  모드안 채택** — 평소 목록은 그대로 두고, 삭제 UI는 "선택" 모드에서만 드러난다.
- **한 일**: 헤더에 "선택" 진입 버튼, 선택 모드에서 각 행 체크박스·행 강조·탭
  토글·스와이프/동작버튼 잠금, 헤더에 전체선택/취소·"N개 선택", 하단 "N개 삭제"
  바 → 확인 다이얼로그 → 일괄 삭제. `WalletViewModel.deleteContacts(ids)`는
  저장소 단건 삭제를 순회(저장소 미변경).
- **검증**: analyze 신규 0, test 333/333. 실기기에서 선택 진입·체크박스·행
  강조·"2개 선택"·하단 바 활성/비활성 라벨 전환·전체선택·취소 복귀 확인.
  하단 삭제 바는 화면 맨 아래 고정이라 **기기 제스처 내비 영역과 겹쳐 adb
  합성 탭이 안 먹혔고**(실제 손가락은 정상), 확인 다이얼로그·취소 시 미삭제는
  **사용자가 실기기 손가락으로 co-verify** 완료.

## 재사용할 교훈

- **실기기 adb 자동화의 사각지대**: 화면 맨 아래에 고정된 버튼은 삼성 One UI
  제스처 내비 영역과 겹쳐 `adb input tap`이 시스템에 먹혀 눌리지 않는다(다른
  위치의 요소는 정상). 이럴 땐 사용자 실손 1탭 co-verify로 메운다.
- **macOS/웹은 이 앱의 실기기 눈확인을 대체하지 못한다**: macOS 데스크톱은
  빌드·실행은 되나 이 환경에 화면 녹화 권한(TCC)이 없어 screencapture가 막히고,
  Flutter 웹은 미지원 플러그인(UnsupportedError)으로 스플래시에서 멈춘다.
  실기기(Android 폴드, adb 스크린샷·탭) 경로가 유일하게 눈확인이 된다.
- **워크트리 격리가 다중 세션 동시작업의 안전장치**: 공유 작업 트리에서
  branch 전환·reset·stash는 다른 세션 변경을 덮어쓴다. 각 F 항목을 origin/main
  기준 격리 worktree로 파서 작업하면 미커밋 변경이 안 딸려오고 충돌이 0이었다.
