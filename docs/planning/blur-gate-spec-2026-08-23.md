# E-06 흐림 방지 — 지표 조사 결과

작성: 2026-08-23 · 근거: 386 표본 8장 실측 · **구현 권고하지 않음**

> ## 🛑 결론: **지금 있는 재료로는 흐림을 못 잰다.**
>
> 후보 셋을 다 재 봤고 셋 다 막혔다. 문턱을 정하는 단계까지 가지 못했다.

---

## 1. 무엇을 하려 했나

E-06(*"흐린 채 인식 진행"*)의 근본 처리로 **자동 셔터에 선명도 조건**을 더하는
것. 지금 조건에는 선명도 항목이 **아예 없고**, 코드 주석도 *"흐린 사진 위험은
촬영 직후 확인 화면이 받아 준다"*로 미뤄 뒀다고 적혀 있다.

## 2. ⚠️ 후보 셋을 다 재 봤다 — 셋 다 막혔다

⚠️ **흐린 실촬영 표본이 없어 기존 표본을 흐리게 만들어 썼다**(가우시안 블러
반지름 2·4). 합성 블러는 실제 손떨림과 다르다(방향성이 없고 균일하다). 다만
**"지표가 흐림에 반응조차 하는가"**를 보는 데는 충분하고, 아래 결과는 전부
*"반응하지 않는다"*이므로 합성/실물 차이가 결론을 뒤집지 않는다.

### 후보 ① 지금 격자(24×24) 라플라시안 — **반응 0**

```
선명 평균 33.6  ·  블러 평균 33.5  ·  배율 1.00
```

**전혀 못 잰다.**

### 후보 ② 격자를 키운다 — **키워도 안 된다**

```
격자    선명   블러   배율    프레임당 샘플
 24    33.6  33.5   1.00        576   ← 지금
 48    35.6  35.4   1.00      2,304
 96    33.7  33.3   1.01      9,216
160    33.5  32.2   1.04     25,600
240    37.7  34.3   1.10     57,600
```

📌 **원인은 축소 자체다.** 격자로 줄이는 것이 이미 저역통과 필터라, 흐림이
지우는 고주파를 **축소가 먼저 지운다.** 240×240에서 겨우 1.10배인데 그건
**지금의 100배 계산**이다.

⚠️ 이 앱은 **발열 때문에 검출 주기를 0.32초로 늦춘 적이 있다**(추가 293).
100배는 논외다.

### 후보 ③ 이미 도는 검출의 신뢰도 — **반응 0**

검출은 매 프레임 돌고 있으니 여기서 신호가 나오면 **공짜**다. 그래서 가장
기대했는데:

```
표본 8장 × (선명·블러2·블러4)  →  최고 신뢰도 **전부 1.000**
사각형 개수도 거의 그대로
```

**사각형 검출은 흐림에 반응하지 않는다.** 테두리는 흐려져도 위치가 남기
때문이다 — 검출기가 보는 것과 사람이 "흐리다"고 느끼는 것이 다르다.

## 3. 그래서 무엇이 필요한가

전체 해상도(또는 큰 크롭)에서 고주파를 재야 한다. **전체 해상도 라플라시안은
선명/블러가 2.3배로 갈린다** — 지표 자체는 멀쩡하다. 문제는 **비용**이다.

| 방법 | 갈리나 | 비용 |
|---|---|---|
| 24×24 격자 | ✘ | 지금 그대로 |
| 큰 격자 | ✘ | 최대 100배 |
| 검출 신뢰도 | ✘ | 공짜인데 신호가 없다 |
| **전체 해상도 라플라시안** | **✔ 2.3배** | **미측정 — 매 프레임은 무리로 보인다** |

⚠️ **네 번째 줄의 비용을 안 쟀다.** 재려면 실기기가 필요하고, 프레임마다가
아니라 **"안정 판정이 선 뒤 한 번만"** 같은 절충도 같이 재야 한다.

## 4. ⚠️ 무엇보다 — **부작용이 이득보다 클 수 있다**

이 프로젝트는 자동 촬영 조건을 조였다가 **두 번** 제보를 받았다.

```
"명함에 가이드를 제대로 놓은 것 같은데 파란색이 잘 보이지 않아"
"조절하고 나니까 명함을 가이드가 파란색으로 변하지를 않아"
```

📌 그리고 386 표본 **8장 중 2장은 사각형이 아예 안 잡힌다**(추가 432). 지금도
그 명함들은 자동 셔터가 안 눌린다. **여기에 선명도 조건을 더하면 안 눌리는
명함이 더 늘어난다.**

⚠️ **흐린 사진은 다시 찍으면 되지만, 셔터가 안 눌리면 사용자는 방법이 없다고
느낀다.** 이 저장소가 *"셔터는 언제든 직접 누를 수 있다"*를 근거로 **막지 않는
쪽**을 택해 온 이유다.

## 5. 권고

**지금은 넣지 않는다.** 근거는 위 셋이 다 막혔다는 것과, 부작용이 이미 두 번
현실이 됐다는 것이다.

다시 볼 조건이 생긴다면:

1. **흐린 실촬영 표본**이 모인다(합성이 아니라)
2. **전체 해상도 라플라시안의 실기기 비용**을 잰다 — 특히 *"안정 판정 뒤 한
   번만"* 절충
3. 그때도 **문턱은 실측으로** 정한다 — 이 저장소는 짐작 문턱으로 두 번 데였다
   (`_minCenterContrast` 10.0, `_minDominantToneRatio` 0.65)

📌 **E-06을 방치하자는 것이 아니다.** 지금도 촬영 직후 *"글자가 또렷한가요?"*
확인 화면이 받고 있고, 그것이 **셔터를 막는 것보다 되돌리기 쉬운 장치**다.
