# 본인확인·알림톡 비용과 손익 영향 (2026-08-25)

**왜 쟀나**: 계정 식별이 I안(리멤버식 — 전화번호가 계정의 주인)으로 확정되면서
**휴대폰 본인확인**이 가입 흐름에 들어온다. 그리고 광고 채널로 **카카오 알림톡**을
알리고를 통해 쓸 예정이다. 둘 다 **건당 돈이 나가는 것**이라 손익에 들어가야 한다.

> ⚠️ **공개 요금과 2차 자료로 잰 것이다. 견적을 받은 것이 아니다.**
> 아래 표의 `공개` 표시는 업체가 공시한 값, `2차`는 기사·정리 글에서 온 값,
> `견적 필요`는 공개돼 있지 않은 값이다. **계약 전에 실제 견적으로 다시 재야 한다.**

---

## 0. 먼저 — 전제 하나가 틀렸을 수 있다

🚨 **알리고는 본인인증을 제공하지 않는다.**

알리고(주식회사 알리는사람들)는 **문자·알림톡 발송 대행**이다. 공식 사이트·고객센터
어디에도 본인확인 상품이 없고, 본인확인은 **KCB·NICE평가정보·SCI평가정보 같은
지정 본인확인기관**이나 그 대행사(KG이니시스·다날·포트원 등)를 따로 계약해야 한다.

```
알리고          카카오 알림톡·친구톡·문자 발송        → 광고 채널
본인확인기관     휴대폰 본인확인, CI/DI 발급          → 가입 흐름
```

📌 **둘은 다른 계약이고 다른 비용이다.** *"카톡알리고를 통해서 예정"*이 두 가지를
한 업체로 묶는 뜻이었다면, **그건 안 된다.**

## 1. 휴대폰 본인확인 — 건당 40원 안팎

| 업체 | 건당 | 초기 구축비 | 근거 |
|---|---|---|---|
| **KG이니시스** 통합본인인증 | **40원** | 명시 없음 (포트원 경유 시 무료) | 2차 |
| **다날** 휴대폰 본인인증 | **41.7원**<br>(5만원/1,200건 ~ 30만원/7,200건, 전 구간 동일) | **10만원**<br>직계약 시 · 포트원 경유 시 무료 | 2차 |
| **SKT PASS** | 초기 45원 → 인하 → **재인상**(현재값 불명) | — | 2차 |
| **NICE평가정보** | **공개 안 됨** | 공개 안 됨 | 공개(요금만 비공개) |

**받는 항목**(NICE 기준, 공개 확인): 이름 · 생년월일 · 성별 · 통신사 · 휴대폰번호
**+ CI/DI**.

📌 **월 기본료·최소 약정은 어느 업체도 공개하지 않는다.** 다날처럼 **월 정액제**로
파는 곳은 사실상 최소 약정이 있는 셈이다(5만원 = 1,200건). **이용자가 적을 때는
건당 단가보다 이 최소액이 더 크다.**

⚠️ **이용자가 내는 게 아니라 회사가 내는 비용이다.** 가입할 때 1회 발생한다.

---

## 2. 🚨 DI는 업체를 바꾸면 달라진다 — I안의 급소

이게 이번 조사에서 **가장 중요한 발견**이다.

```
CI (연계정보)          어느 본인확인기관에서 발급해도 같은 사람이면 같은 값
DI (중복가입확인정보)   같은 사람이라도 인증 업체가 다르면 다른 값
```

**I안을 고른 이유는 이중등록 원천 차단**이다. 그런데 중복 판정을 **DI로 하면**,
나중에 본인확인 업체를 바꾸는 순간 **기존 이용자 전원의 DI가 새로 발급되어 예전
값과 안 맞는다.** 그러면 중복 판정이 통째로 깨지고, **같은 사람이 새 사람으로
보인다** — 막으려던 바로 그 일이 일어난다.

📌 **그래서 이건 요금 비교보다 먼저 정할 문제다.**

| 무엇으로 중복을 판정하나 | 결과 |
|---|---|
| **DI** | 업체를 못 바꾼다(사실상 종속). 바꾸려면 전원 재인증 |
| **CI** | 업체를 바꿔도 값이 유지된다. 대신 더 민감한 정보라 취급이 무겁다 |

⚠️ **업체를 고르기 전에 "DI냐 CI냐"를 먼저 정해야 한다.** 싸다고 골랐다가 나중에
못 옮기는 상황이 이 결정에 달려 있다. **법률 검토가 필요한 자리로 보인다**(CI는
연계정보라 수집·보관 요건이 다르다) — 이건 계정 I안을 잡고 있는 세션 몫이다.

## 3. 카카오 알림톡(알리고) — 광고 채널

| 무엇 | 건당 | 근거 |
|---|---|---|
| **알림톡** | **6.5원** | 공개 |
| 브랜드 메시지(친구) | 19.9원 | 공개 |
| 브랜드 메시지(비친구) | 27.2원 | 공개 |
| 문자 단문(SMS) | 8.4원 | 공개 |
| 문자 장문(LMS) | 25.9원 | 공개 |
| 문자 그림(MMS) | 60원 | 공개 |

**전부 부가세 별도.** 충전 잔액은 **5년** 유효, 발송 실패분은 자동 환불,
**080 수신거부 서비스 무료 제공**.

⚠️ **카카오 채널 개설비·월 이용료가 따로 있는지는 알리고 페이지에 없다.**
`견적 필요`.

📌 **알림톡(6.5원)과 친구톡·브랜드 메시지(19.9~27.2원)는 성격이 다르다.**
알림톡은 원칙적으로 **정보성**이고 광고는 친구톡 쪽이다. 우리가 보내려는 것은
**광고**이므로 **19.9원 이상**을 잡아야 할 수 있다.
⚠️ 이건 확인 못 했다 — **카카오 심사 기준의 문제**라 알리고 요금표만으로는 안 된다.

## 4. 손익 영향 — 목표 규모에 넣어 본다

기준: 마케팅 계획의 **6개월 무료 10,000명 · 유료 100명**, 손익분기 유료 전환율
**0.14%**, 충전 티어 **₩1,000·30회 / ₩3,000·100회 / ₩5,000·200회 / ₩10,000·450회**.

### (가) 본인확인 — 1회성이지만 **무료 이용자에게도 든다**

```
10,000명 × 40원 = 400,000원   (계산)
```

⚠️ **이 400,000원은 가입자 전원에게 나간다.** 유료로 전환되지 않는 9,900명에게도
든다. 즉 **가입자당 고정 획득비용 40원**이 새로 생긴다.

**이것이 손익분기에 미치는 영향** (계산, 가정은 아래):

```
가정   유료 100명이 평균 ₩3,000 티어를 산다  →  매출 300,000원
결과   본인확인 400,000원 > 유료 매출 300,000원
```

🚨 **목표를 달성해도 본인확인 비용이 유료 매출보다 크다.**

**손익분기 전환율로 보면** — 기존 0.14%(10,000명 중 14명)로는 약 42,000원이
들어온다. 여기에 본인확인 400,000원이 얹히면 **약 133명이 더 필요**해져
전환율이 **약 1.5%**가 된다. **열 배 가까이 오른다.**

⚠️ **이 계산은 "평균 ₩3,000 티어" 가정에 크게 의존한다.** 실제 티어 분포는
아직 데이터가 없다. **가정을 바꾸면 결론이 바뀐다** — 그래서 이건 *"본인확인을
넣으면 안 된다"*가 아니라 **"공짜로 넣을 수 있는 게 아니다"**를 말한다.

### (나) 알림톡 — 되풀이되는 비용

```
10,000명 × 월 1회 × 6.5원  =  월 65,000원      (알림톡 단가로 계산)
10,000명 × 월 1회 × 19.9원 =  월 199,000원     (친구톡 단가로 계산)
```

⚠️ **월 1회만 보내도** 알림톡 기준 **연 78만원**, 친구톡 기준 **연 239만원**이다.
현재 저장소 비용(1.2TB, 월 4.1만원)보다 크다.

📌 **광고 수신 동의율이 100%일 리 없으므로 실제로는 이보다 적다.** 다만 동의율을
아직 모른다 — **동의 화면을 배포한 뒤에야 잰다.**

### (다) 합쳐 보면

| 항목 | 성격 | 목표 규모에서 |
|---|---|---|
| 본인확인 | **1회성**(가입 시) | 40만원 |
| 알림톡 | **되풀이** | 월 6.5만 ~ 20만원 |
| AI 원가 | 되풀이 | 회당 ₩3.29 |
| 저장소 | 되풀이 | 월 4.1만원 |

⭐ **성격이 다르다는 것이 핵심이다.** 본인확인은 **가입자 수에 비례해 한 번**,
알림톡은 **가입자 수 × 보내는 횟수만큼 매달**. 이용자가 늘수록 알림톡이 본인확인을
금방 넘는다.

## 5. 돈 말고 다른 대가 — 이건 요금표에 안 나온다

⚠️ **본인확인을 가입에 넣으면 가입 자체가 무거워진다.**

지금은 SNS 버튼 하나로 끝나는데, 본인확인이 들어오면 **통신사 선택 → 약관 동의 →
인증번호**가 붙는다. 가입 중 이탈이 얼마나 늘지는 **재 봐야 안다.**

📌 이 앱의 목표가 **6개월에 무료 10,000명**이고 예산이 0원에서 시작하는 계획이라,
**가입 이탈률 상승은 광고비로 환산하면 40원보다 훨씬 클 수 있다.**

⚠️ 이건 **재지 않았다.** 짐작으로 숫자를 넣지 않는다.

**얻는 것도 같이 적는다** — 이중등록 원천 차단, **만 14세가 자기 선언에서 통신사
검증으로** 바뀌어 과징금(매출 3% 이하) 위험이 줄어든다. 후자는 광고 수신 동의
법률 조사(추가 457)에서 **금액 상한이 정액이 아닌 유일한 항목**이었다.

## 6. 결론과 남은 것

**지금 말할 수 있는 것**
1. 본인확인은 **건당 40원 안팎**, 가입 시 1회. 무료 이용자에게도 든다
2. 알림톡은 **건당 6.5원**(광고면 19.9원일 수 있음), 매달 되풀이
3. **알리고로는 본인확인을 못 한다** — 별도 계약이 필요하다
4. 🚨 **DI로 중복을 판정하면 업체를 못 바꾼다** — 요금보다 먼저 정할 문제
5. 목표 규모에서 **본인확인 비용이 유료 매출과 같은 자릿수**다

**견적을 받아야 채워지는 칸**

| 무엇 | 왜 필요한가 |
|---|---|
| 본인확인 **월 기본료·최소 약정** | 이용자가 적을 때 건당보다 이게 크다 |
| **DI/CI 제공 조건**과 요금 포함 여부 | I안의 목적이 여기 달려 있다 |
| 카카오 **채널 개설비·월 이용료** | 알리고 페이지에 없다 |
| **광고성 알림톡의 실제 단가** | 6.5원인지 19.9원인지 — 카카오 심사 기준 문제 |
| 유료 **티어 분포** | §4의 계산이 여기 크게 의존한다 |
