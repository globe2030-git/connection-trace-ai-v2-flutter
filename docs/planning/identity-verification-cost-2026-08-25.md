# 휴대폰 인증·알림톡 비용과 손익 영향 (2026-08-25)

**왜 쟀나**: 계정 식별이 I안(리멤버식 — 전화번호가 계정의 주인)으로 확정되면서
**휴대폰 인증**이 가입 흐름에 들어온다. 그리고 광고 채널로 **카카오 알림톡**을 쓴다.
둘 다 **건당 돈이 나가는 것**이라 손익에 들어가야 한다.

> ⚠️ 업체 요금은 **공개 자료와 2차 자료로 잰 것**이다. 표의 `공개`는 업체가 공시한 값,
> `2차`는 기사·정리 글, `사용자 확인`은 사용자가 알려 준 실제 진행값, `견적 필요`는
> 공개돼 있지 않은 값이다. **계약 전에 실제 견적으로 다시 재야 한다.**

---

## 0. 🚨 먼저 — 용어가 갈린다. 그리고 갈리는 건 말이 아니라 제품이다

사용자 정정(2026-08-25): *"본인인증이 아닌 **핸드폰인증**이 정확한 표현이겠네.
**핸드폰 주인이 맞는지**가 중요한 거잖아."*

**맞는 지적이고, 이 구분이 이 문서의 결론을 바꾼다.** 한국에서 이 둘은 다른 상품이다.

| | **휴대폰 인증**(번호 점유 확인) | **휴대폰 본인확인**(신원 검증) |
|---|---|---|
| 무엇을 확인하나 | **이 번호로 오는 문자를 받을 수 있는가** | 통신사 가입자 정보와 **이름·생년월일이 맞는가** |
| 받는 항목 | 전화번호만 | 이름 · 생년월일 · 성별 · 통신사 · 번호 **+ CI/DI** |
| 누가 파나 | 문자 발송사(알리고 등) | **지정 본인확인기관**(NICE·KCB 등)과 대행사 |
| 건당 | **6.5~8.4원** | **40원 안팎** |
| 만 14세 | ❌ 나이를 알 수 없다 | ✅ **통신사 정보로 검증** |
| 중복가입 판정 | 전화번호 자체로 한다 | DI로 한다 |

📌 **사용자가 말한 "핸드폰 주인이 맞는지"는 왼쪽이다.** 그렇다면 40원짜리가 아니라
**6.5~8.4원짜리**로 충분하고, 이 문서의 비용 결론이 통째로 달라진다.

⚠️ **다만 왼쪽을 고르면 두 가지를 잃는다.** 아래 §2와 §3에서 따로 잰다.

## 1. 값 — 두 갈래

### (가) 휴대폰 인증 — 우리가 문자를 보내고 번호를 확인한다

| 무엇 | 건당 | 근거 |
|---|---|---|
| **알림톡** | **6.5원** (부가세 별도) | **사용자 확인 — 현재 이 단가로 진행 중** |
| 문자 단문(SMS) | 8.4원 | 공개(알리고) |

📌 **인증번호를 알림톡으로 보내면 6.5원, 문자로 보내면 8.4원**이다. 알림톡은 카카오가
없는 이용자에게 안 가므로 **실패 시 문자로 대체(fallback)**하는 구성이 보통이다.

⚠️ **재발송을 세야 한다.** 인증번호는 안 오면 다시 보낸다. 1인당 1건이 아니라
**1.2~1.5건**으로 잡는 편이 안전하다(가정 — 재발송률은 재 보지 않았다).

### (나) 휴대폰 본인확인 — 본인확인기관을 거친다

| 업체 | 건당 | 초기 구축비 | 근거 |
|---|---|---|---|
| **KG이니시스** 통합본인인증 | **40원** | 명시 없음(포트원 경유 시 무료) | 2차 |
| **다날** 휴대폰 본인인증 | **41.7원**<br>(5만원/1,200건 ~ 30만원/7,200건, 전 구간 동일) | **10만원**<br>직계약 시·포트원 경유 시 무료 | 2차 |
| **SKT PASS** | 초기 45원 → 인하 → **재인상**(현재값 불명) | — | 2차 |
| **NICE평가정보** | **공개 안 됨**(견적 문의) | 공개 안 됨 | 공개 |

⚠️ **월 기본료·최소 약정은 어느 업체도 공개하지 않는다.** 다날처럼 **월 정액제**로 파는
곳은 사실상 최소액이 있다(5만원 = 1,200건). **이용자가 적을 때는 건당보다 이게 크다.**

## 2. 🚨 휴대폰 인증만 하면 잃는 것 ① — 만 14세를 검증하지 못한다

광고 수신 동의 법률 조사(추가 457)에서 만 14세는 **이번 조사에서 금액 상한이 정액이
아닌 유일한 항목**이었다 — 과태료가 아니라 **과징금(매출 3% 이하)**이다.

```
휴대폰 인증만        나이를 모른다  →  "만 14세 이상입니다" 자기 선언 유지
휴대폰 본인확인       생년월일이 온다 →  통신사 정보로 검증
```

📌 지금 로그인 화면에 들어간 `[필수] 만 14세 이상입니다` 체크는 **자기 선언**이다.
휴대폰 인증만 하면 **그 상태가 그대로 남는다.**

⚠️ 조사에서 **연령 확인의 명문 의무는 없음을 확인**했고, 개인정보위 가이드라인이
**권장**하는 것이 바로 그 자기 선언이다. 즉 **자기 선언이 위법은 아니다.** 다만
방침·약관이 *"만 14세 미만의 가입을 제한한다"*고 선언해 두었으므로, **선언과 실제
사이의 간격이 남는다.**

---

## 3. 🚨 휴대폰 인증만 하면 잃는 것 ② — 번호 재사용

전화번호를 계정의 주인으로 쓰면, **번호가 남에게 넘어갈 때 계정도 같이 넘어갈 수
있다.**

```
2023-04-01부터   해지된 번호는 90일이 지나야 새 가입자에게 배정된다
                 (그 전에는 28일이었다 — 약 3배로 늘었다)
```

**즉 90일 뒤에는 다른 사람이 그 번호의 주인이다.** 그 사람이 우리 앱에 가입하면서
같은 번호로 인증하면, **전 주인의 계정에 닿을 수 있다.**

⚠️ **이 앱에서는 그 계정 안에 제3자(명함 주인) 개인정보가 수백 장 들어 있다.**
일반적인 서비스보다 사고의 무게가 다르다.

**본인확인(CI/DI)으로 하면 이 문제가 줄어든다** — 사람이 바뀌면 CI/DI가 다르므로
번호가 같아도 다른 사람으로 판정된다.

📌 **그래서 §0의 표에서 "중복가입 판정"이 갈렸던 것이다.**

| 무엇으로 판정하나 | 업체를 바꿀 수 있나 | 번호가 남에게 가면 |
|---|---|---|
| **전화번호** | ✅ 자유롭다 | 🚨 **전 주인 계정에 닿을 수 있다** |
| **DI** | ❌ 못 바꾼다(바꾸면 전원 재발급 → 중복 판정 붕괴) | ✅ 다른 사람으로 판정 |
| **CI** | ✅ 바꿔도 유지 | ✅ 다른 사람으로 판정 |

⚠️ **DI는 업체 종속, 전화번호는 번호 재사용.** 둘 다 공짜가 아니다. CI만 양쪽을
피하는데, **CI는 연계정보라 수집·보관 요건이 더 무겁다**(법률 검토 필요 — 계정 I안
담당 세션 몫).

📌 **완화책은 있다.** 예를 들어 마지막 접속으로부터 오래 지난 계정은 재인증을
요구하거나, 번호가 같아도 **기존 계정에 바로 들어가지 않고 확인 단계**를 두는 식이다.
⚠️ 다만 **어느 것도 재 보지 않았다.** 여기서는 위험이 있다는 것까지만 적는다.

## 4. 카카오 알림톡 — 광고 채널

| 무엇 | 건당 | 근거 |
|---|---|---|
| **알림톡** | **6.5원** (부가세 별도) | **사용자 확인 — 현재 진행 중** |
| 브랜드 메시지(친구) | 19.9원 | 공개(알리고) |
| 브랜드 메시지(비친구) | 27.2원 | 공개(알리고) |
| 문자 단문 / 장문 / 그림 | 8.4 / 25.9 / 60원 | 공개(알리고) |

✅ **광고 단가는 이미 정해져 진행 중이다**(6.5원, 부가세 별도). 앞선 판에서
*"광고성이면 19.9원일 수 있다"*고 적었으나, **사용자 확인으로 6.5원이 맞다.**

⚠️ **업체가 둘로 나뉘어 있을 수 있다.** 사용자가 알림톡 광고는 **티킹**에서
진행한다고 알려 주었고, 알리고는 별개로 언급됐다. **어느 업체를 쓰는지, 하나인지
둘인지는 확인이 필요하다** — 요금이 같아도 계약·정산·발송 API가 달라진다.

## 5. 손익 영향 — 갈래별로

기준: 마케팅 계획의 **6개월 무료 10,000명 · 유료 100명**, 손익분기 유료 전환율
**0.14%**, 충전 티어 **₩1,000·30회 / ₩3,000·100회 / ₩5,000·200회 / ₩10,000·450회**.

### (가) 가입 인증 — 1회성이지만 **무료 이용자에게도 든다**

```
휴대폰 인증(알림톡 6.5원 × 재발송 1.3회 가정)   10,000명 →   84,500원
휴대폰 본인확인(40원)                          10,000명 →  400,000원
                                              차이     ≈  315,500원
```

📌 **약 32만원 차이**다. 유료 100명이 평균 ₩3,000 티어를 산다고 보면 매출 30만원이니,
**그 차이 하나가 목표 유료 매출과 같은 자릿수**다.

**손익분기 유료 전환율에 미치는 영향**(계산, 가정은 위와 같음):

| | 가입 인증 비용 | 손익분기 전환율 |
|---|---|---|
| 인증 없음(현재) | 0원 | **0.14%** |
| 휴대폰 인증 | 8.5만원 | 약 **0.4%** |
| 휴대폰 본인확인 | 40만원 | 약 **1.5%** |

⚠️ **이 계산은 "유료 이용자가 평균 ₩3,000 티어를 산다"는 가정에 크게 기댄다.** 실제
티어 분포 데이터가 없다. **가정을 바꾸면 결론이 바뀐다.**

### (나) 광고 알림톡 — 되풀이되는 비용

```
10,000명 × 월 1회 × 6.5원  =  월 65,000원  (연 78만원)
```

⚠️ **월 1회만 보내도** 현재 저장소 비용(1.2TB, 월 4.1만원)보다 크다.

📌 **광고 수신 동의율이 100%일 리 없으므로 실제로는 이보다 적다.** 동의율은
**동의 화면을 배포한 뒤에야 잰다.**

### (다) 성격이 다르다

| 항목 | 성격 | 목표 규모에서 |
|---|---|---|
| 가입 인증 | **1회성**(가입 시) | 8.5만 ~ 40만원 |
| 광고 알림톡 | **되풀이** | 월 6.5만원 |
| AI 원가 | 되풀이 | 회당 ₩3.29 |
| 저장소 | 되풀이 | 월 4.1만원 |

⭐ **가입 인증은 가입자 수에 비례해 한 번, 알림톡은 가입자 수 × 보내는 횟수만큼
매달.** 이용자가 늘수록 알림톡이 가입 인증을 금방 넘는다.

## 6. 돈 말고 다른 대가 — 요금표에 안 나온다

⚠️ **인증을 가입에 넣으면 가입 자체가 무거워진다.** 지금은 SNS 버튼 하나로 끝난다.

```
휴대폰 인증        번호 입력 → 문자 받기 → 번호 입력          (단계 3)
휴대폰 본인확인     통신사 선택 → 약관 동의 → 인증 → 확인      (단계 4+)
```

가입 중 이탈이 얼마나 늘지는 **재 봐야 안다.** 목표가 6개월에 무료 10,000명이고
예산이 0원에서 시작하는 계획이라, **이탈률 상승은 광고비로 환산하면 건당 단가보다
훨씬 클 수 있다.**

⚠️ 이것은 **재지 않았다.** 짐작으로 숫자를 넣지 않는다.

## 7. 결론

**용어부터 바로잡는다** — 필요한 것은 *"핸드폰 주인이 맞는지"*이므로 **휴대폰 인증**이
정확하다. 그러면 **건당 40원이 아니라 6.5~8.4원**이고, 가입 인증 비용이 **40만원에서
약 8.5만원으로 내려간다.**

**대신 둘을 잃는다.**
1. **만 14세 검증** — 자기 선언이 그대로 남는다(위법은 아니나 방침 선언과 간격이 남음)
2. **번호 재사용** — 해지 90일 뒤 남에게 간 번호로 전 주인 계정에 닿을 수 있다.
   ⚠️ 이 앱은 그 계정 안에 **제3자 개인정보가 수백 장** 들어 있다

**광고 단가는 이미 정해져 있다** — 알림톡 6.5원, 부가세 별도, 진행 중.

**정할 것**

| 무엇 | 누가 |
|---|---|
| 휴대폰 인증이냐 본인확인이냐 | **사용자** — 이 문서의 값으로 고를 수 있다 |
| 중복 판정을 전화번호/DI/CI 중 무엇으로 | 계정 I안 담당(법률 검토 필요) |
| 번호 재사용 완화책 | 계정 I안 담당 |
| 알림톡 업체(티킹/알리고) 정리 | **사용자 확인 필요** |

**견적을 받아야 채워지는 칸**: 본인확인 **월 기본료·최소 약정** · **DI/CI 제공 조건**과
요금 포함 여부 · 카카오 **채널 개설비·월 이용료** · 인증번호 **재발송률** · 유료
**티어 분포**
