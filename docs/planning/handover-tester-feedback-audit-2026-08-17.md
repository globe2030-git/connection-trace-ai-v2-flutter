## 2. ⚠️ 그런데 오늘 결론이 문서를 무너뜨렸습니다 — **여기가 핵심입니다**

문서는 이렇게 적혀 있습니다:

> *"E-01·E-06 잔여분이 R-02(문서 경계 검출)로 흡수된다"*

**그 자르기(B′)를 오늘 안 쓰기로 했습니다.** 세 번 재서 *"기존 가이드보다
낫다는 증거가 없다"*가 결론이고, **기본값은 꺼진 채로 병합**됐습니다
(추가 277, PR #266·#267·#268).

```
E-01  자동 촬영이 빈 공간을 찍음   ← 자르기가 닫아 줄 예정이었다
E-06  초점 안 맞은 채 OCR         ← 〃
F-03  손으로 자르기                ← 〃
```

⚠️ **세 건이 "닫힐 예정"에서 "다시 열림"으로 돌아갔을 수 있습니다.**
**첫 번째로 확인할 것이 이것입니다.** 확인하고 문서를 고치십시오.

## 3. 확인할 것 — 이 셋만 보십시오

### ① 남은 4건이 지금도 유효한가

| | | 오늘 달라진 것 |
|---|---|---|
| **E-04** 글자 오독(`길`→`킬`) | 다중 OCR(R-03)로만 풀림 | 📌 **근거가 생겼습니다** — 103장 측정에서 **직함 오류의 42%가 오독**(추가 280) |
| **E-12** 위치 정확도 | 문서엔 "남음" | ⚠️ **8/16에 코드가 들어갔습니다** — `lib/core/utils/location_quality.dart`. 문서가 안 따라왔습니다 |
| **E-01·E-06** | "자르기가 흡수" | ⚠️ **2절 참조 — 그 전제가 깨졌습니다** |
| **F-01·F-03** | 부분 | F-03은 위와 같음 |

### ② "종결"인데 실물을 못 본 것 셋

문서가 스스로 ⚠️ 표시해 둔 것들입니다. **실기기가 필요합니다.**

- **F-10** "오늘 연락하면 좋은 사람" — 30일 초과 대상이 없어 화면에 뜬 적 없음
- **F-13** 근접 알림이 실제 내 위치를 쓰는지 — `nearbyAlertContact`가 **UI에 안 붙어 있음**
- **F-15** 같은 주소 묶음 머리글 — 실제 데이터에 같은 주소 짝이 없었음

⚠️ **기기를 쓰기 전에 PM에게 요청하십시오.** 지금 다른 세션이 쓰고 있을 수 있습니다.
