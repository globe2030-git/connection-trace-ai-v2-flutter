1 · 브리핑 오버레이 — 빈 상태

lib/presentation/features/briefing/views/briefing_overlay_view.dart 변경됨

전체화면 오버레이(반투명 검정 배경). 기존엔 "AI 연동이 필요합니다"(BYOK) 카드가 여기 있었는데, 서버 프록시 전환 후엔 연동 개념 자체가 없어져 이 카드가 사라지고 바로 "AI 가이드 만들기" 빈 상태로 시작한다. 단, 서비스가 아직 준비 중이면 대신 분기 상태(아래 1-B)가 뜬다.

⚡ 30초 AI 대화 브리핑

아직 생성된 AI 가이드가 없습니다.
전송할 정보를 먼저 확인한 뒤
직접 생성할 수 있습니다.

✨ AI 가이드 만들기
실제 문구(기존 코드 그대로)
"아직 생성된 AI 가이드가 없습니다. 전송할 정보를 먼저 확인한 뒤 직접 생성할 수 있습니다."
변경 사항
  • 기존에 있던 "AI 연동이 필요합니다" 카드(activeProvider == null 분기) 삭제 — 연동이라는 개념이 없어짐
  • "AI 가이드 만들기" 탭 시 바로 화면 2(동의 시트)로 진입 — 기존과 동일한 흐름 유지

1-B · 서비스 준비 중 (분기)

briefing_overlay_view.dart 신규

Cloud Functions(generateBriefing)가 아직 배포되지 않은 지금 상태에서 "AI 가이드 만들기"를 누르면 이 상태가 뜬다. 배포 완료 후엔 이 분기 자체가 없어지고 화면 1 → 2로 바로 이어진다.

2 · 전송 정보 확인·동의

lib/presentation/features/briefing/views/ai_data_review_sheet.dart 변경됨

바텀시트. 구조·소통기록 선택 UI는 그대로 두고, "어디로 전송되는가" 문구만 제공사 이름 → 회사 서버 경유로 수정한다. 이 화면을 매 요청마다 반드시 거치는 원칙은 유지(자동 백그라운드 전송 없음).

🛡️ AI에 보낼 정보 확인

선택한 정보만 회사 서버를 거쳐 AI로 전송합니다. 앱이 백그라운드에서 자동 전송하지 않습니다.

항상 포함되는 기본 정보

상대방: 이름, 직함, 회사
태그: AI, IT, 디자이너

☑ 카카오톡 — 다음 주 일정 확인차…

동의는 이번 요청에만 적용됩니다.

  • 소통기록 CheckboxListTile 다중 선택 + 선택 개수 카운터
  • 동의 체크 전엔 버튼 비활성화

3 · 로딩

briefing_overlay_view.dart 기존 유지

서버 프록시 호출이라 왕복 시간이 기존(클라이언트→AI 제공사 직접)보다 약간 늘어날 수 있음 — UI 자체는 동일한 스피너 유지.

동작
  • 결과가 하나도 없을 때만 중앙 전체화면 스피너
  • 기존 결과가 있는 상태에서 재생성 중이면 헤더 새로고침 아이콘만 작은 스피너로 대체(전체 화면 안 가림)

4 · 결과

briefing_overlay_view.dart 기존 유지

대화 포인트 3개를 카드로 나열, 탭해서 하나를 선택(강조 표시)할 수 있음. 하단엔 항상 "안부 전화 걸기" 버튼 고정.

⚡ 30초 AI 대화 브리핑
◉ "지난주 회의 때 말씀하신 프로젝트는 잘 진행되고 계신가요?"
○ "디자이너 채용은 잘 되고 계신지 궁금해서 연락드렸어요."
○ "오늘 날씨도 좋은데, 조만간 커피 한 잔 어떠세요?"
📞 안부 전화 걸기
인터랙션
  • 카드 탭 → 선택 전환(원형 아이콘 채움 + 테두리/배경 강조)
  • 헤더 새로고침 아이콘으로 재생성 가능(기존 결과 유지한 채)

4-B · 에러 상태

briefing_overlay_view.dart 기존 유지 + 메시지 매핑 추가

서버 함수가 resource-exhausted(한도 초과)를 던지면 서버가 만든 문구(예: "오늘 사용 가능한 AI 브리핑 횟수를 모두 사용했어요")가 그대로 이 카드에 노출된다.

⚡ 30초 AI 대화 브리핑
⚠️

오늘 사용 가능한 AI 브리핑 횟수를 모두 사용했어요. 내일 다시 시도해 주세요.

다시 시도
에러 코드 → 문구 매핑
  • resource-exhausted → 서버 메시지 그대로("오늘/이번 달 한도" 문구, 서버 코드에 이미 있음)
  • unauthenticated → "로그인 후 이용할 수 있어요."
  • unavailable / not-found → 화면 1-B "서비스 준비 중"으로 대체
  • 그 외 → "대화 포인트를 생성하지 못했습니다"(기존 문구 유지)
