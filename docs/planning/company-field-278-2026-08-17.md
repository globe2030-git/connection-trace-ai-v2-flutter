# 회사 칸 고르기 — **60% → 67%** (2026-08-17, 추가 278)

**표본** 103장(사람이 전수 검수) · **다른 열 칸은 한 자리도 안 움직였다**

```
회사   60% → 67%   (일치 62 → 69)
전체   85% → 86%
```

## 0. 무엇을 고쳤나 — **고르기를 다시 하지 않고, 고른 값에서 빼기만 했다**

103장 측정(추가 280)에서 회사 오류 39건 중 **26건이 *"OCR은 제대로 읽었는데
파서가 못 고른 것"***이었다. 그중 손댈 수 있는 세 덩어리를 잡았다.

| 무엇 | 어떻게 | 얻은 장 |
|---|---|---|
| **기관 접미사가 목록에 없었다** | `협회`·`학회`·`정보원`을 회사 키워드에 추가 | **+4** |
| **회사명 뒤에 직함이 붙어 있다** | `(주)제이투이 영업대표/부장` → `(주)제이투이` | **+2** |
| **짝 없는 닫는 괄호** | `)유에이엠코리아텍(주)` → 앞의 `)` 제거 | **+1** |

📌 **접미사 추가가 가장 값싼 수였다.** 목록에 넣기만 하면 기존
`_trimCompanyAroundKeyword`가 이미 올바르게 동작한다 — 새 코드가 아니라
**이 저장소가 이미 쓰던 방식**이다.

```
`SSiS 한국사회보장정보원 국민 맞춤형 복지를 실현하는 디지털 플랫폼 전문기관`
  → `한국사회보장정보원`
```

⚠️ **직함 칸은 건드리지 않았다.** 회사명에서 뗀 직함을 직함 칸으로 옮기고
싶었지만, 그러면 이 변경이 직함 숫자까지 흔든다. 278은 **회사 칸만** 손보는
작업이다(직함은 오류의 42%가 OCR 오독이라 방법이 다르다 — 추가 280).

## 1. ⚠️⚠️ 하려다 물린 것 — **로고 떼기**

**이 문서에서 가장 중요한 대목이다.**

처음에는 회사명 앞의 로고도 뗐다. `GO 선호라이팅 (주)` → `선호라이팅 (주)`.
`SK telecom`의 `SK`를 지우지 않으려고 *"뒤쪽에 회사 접미사가 있을 때만"*이라는
안전장치까지 걸었다.

**103장으로 재 보니 3장 얻고 9장 잃었다.** 회사 64% → **60%**.

### 원인은 파서가 아니라 정답지였다

**로고를 회사명에 넣을지가 장마다 다르다.**

```
card_23 · card_38   "SSiS 한국사회보장정보원"   ← 로고 포함
card_125            "한국사회보장정보원"        ← 같은 기관인데 로고 제외

KYWA 한국청소년활동진흥원 (4장)
kmong (주) 크몽 (2장)
DMP Company
```

⚠️ **어느 쪽으로 만들어도 한쪽은 틀린다.** 규칙을 더 정교하게 짜서 풀 문제가
아니다. **정답지에서 로고를 어떻게 적을지 먼저 정해야 한다.**

📌 정하기 전에 파서를 한쪽으로 맞추면 **숫자만 움직이고 사용자가 보는 값은 안
나아진다.** 그래서 물렸고, **물렸다는 사실을 검사로 고정했다** — 다음 사람이
같은 길로 다시 들어가지 않도록.

```dart
test('📌 회사명 앞의 로고 글자를 떼지 않는다 — 정답지가 로고를 포함한다', …)
test('📌 진짜 회사명의 첫 토큰을 자르지 않는다 — SK telecom', …)
```

### 📌 사용자에게 물을 것

**명함에 `KYWA 한국청소년활동진흥원`이라고 인쇄돼 있을 때, 회사 칸에 무엇이
들어가야 합니까?**

```
①  KYWA 한국청소년활동진흥원   (인쇄된 그대로)
②  한국청소년활동진흥원        (로고를 뺀 기관명)
```

정해지면 **정답지를 그 규칙으로 통일**하고, 파서를 거기 맞춘다. 지금은 정답지가
①과 ②를 섞어 쓰고 있어 어느 쪽으로도 못 맞춘다.

## 2. PM이 미리 짚은 위험 — **확인했고, 일어나지 않았다**

> *"회사와 이름은 명함 위쪽에서 자리를 다툰다. 회사를 잘 고르게 만들면 이름이
> 밀려날 수 있다."*

착수 전에 *"회사 정답이 다른 칸으로 간 5건"*이 **어느 칸으로 갔는지** 먼저 봤다.

```
상세주소 4건 · 직함 1건 · 이름 0건
```

**이름으로 간 것은 하나도 없었다.** 그리고 고친 뒤 측정에서도 이름은 86% ·
일치 89로 **한 자리도 안 움직였다.**

⚠️ 다만 이건 *"이 방식으로는 안 밀렸다"*이지 *"회사를 더 손봐도 안전하다"*가
아니다. 이번 변경이 **고르기를 다시 하지 않고 이미 고른 값에서 빼기만 했기**
때문이다. 고르는 순서를 건드리면 이야기가 달라진다.

## 3. 남은 것 — 왜 여기서 멈추나

회사 오류가 아직 **34건**(틀림 27 · 미검출 5 · 오검출 2) 남아 있다. 남은 것은
성격이 달라 같은 방식으로 못 줄인다.

| 덩어리 | 예 | 왜 어려운가 |
|---|---|---|
| **정답지 쪽이 이상함** | card_30 회사 정답이 `nomadspace@naver.com` · card_133 정답이 `대표` | 파서를 고칠 일이 아니다 |
| **로고를 골라버림** | `TENTUREcORPANY`(크림하우스) · `BUSAN, KOREA`(SK telecom) | 고르는 **순서**를 건드려야 한다 → 이름이 밀릴 위험 |
| **OCR 오독** | `VENTU류ECOMPANY` · `RAUM fax` | 규칙으로 못 고친다. R-03 쪽 |
| **한 조직에 몰림** | 한국사회보장정보원 6장 · 한국청소년활동진흥원 4장 | ⚠️ 여기 맞추면 **숫자만 오르고 일반화가 안 된다** |

📌 **마지막 줄이 중요하다.** 103장 중 같은 조직 명함이 여럿이라, 특정 조직에
맞는 규칙을 넣으면 점수는 크게 오르지만 **다른 명함에는 아무 도움이 안 된다.**
이번에 넣은 `협회`·`정보원`도 그 경계에 있다 — 일반적인 기관 접미사라 넣었지만,
**측정값의 일부는 한 조직에서 왔다.**
