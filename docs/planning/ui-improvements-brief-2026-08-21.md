## ⑤ 명함 상세 시트 개선 — `contact_detail_view.dart`

사용자 직접 요청(스크린샷 표시 기반). 셋을 한 번에:

1. **큰 파란 "전화" 띠 버튼 제거.** 화면을 차지하고 부담스럽다는 제보.
2. **연락처 줄마다 오른쪽에 동작 아이콘.**
   - 휴대폰 줄: 전화 + 문자(두 개) · 사무실 줄: 전화 · 이메일 줄: 메일
   - 40dp 원형(accentSoft 배경, accentText 아이콘), 터치 영역 44dp 이상
   - **값이 없는 줄은 아이콘을 그리지 않는다** (빈 상태 그대로 — 가짜 데이터 원칙)
   - 접근성 라벨: "OOO에게 전화", "문자 보내기", "이메일 보내기"
3. **하단 닫기·편집 통일** — 같은 크기, 같은 무채색 외곽선 스타일(파란 강조
   제거), 나란히 배치.

⚠️ 주의:
- 띠에 전화 외 동작(AI 브리핑 등)이 함께 있었다면 **그 진입로는 없애지 말고**
  기존 다른 위치(목록 행의 AI 버튼 등)와 중복인지 확인 후 처리 — 진입로가
  사라지는 변경은 별도 보고.
- 전화·문자·메일 실행은 기존 앱의 launch 경로(목록 행의 전화 버튼과 같은
  코드)를 재사용한다. 새 권한·새 플러그인 금지.

## ⑥-C 주변 홈 지도 카드 — `radar_view.dart` 요약 카드

**⚠️ 착수 게이트: PR #401 병합 후.** 같은 파일을 #401(지역 구획 표시)이 고치고
있다 — 먼저 들어가면 충돌한다.

A안(실시간 지도)은 **미채택** — 방침 10-3(*"지도 화면을 열지 않으면 어떤
요청도 발생하지 않는다"*) 수정과 타일 요청 비용 때문. **C안 확정**:

1. 기존 요약 카드("지금 가까운 사람 N명", map.jpg 배경)를 **높이 ~300dp의
   지도풍 카드**로 확대.
2. 배경은 **앱이 직접 그린 사실적 지도풍 그래픽** — 크림 바탕, 테두리 있는
   흰 도로망(간선은 노란 중앙선), 건물 발자국, 공원 녹지, 물길. 캔버스
   ⑥-C 아트보드의 SVG 구도를 기준으로 CustomPainter 또는 번들 벡터로 구현.
   **외부(지도 사업자) 요청 0을 유지한다** — 방침 10-3이 이 구현의 전제다.
3. 그 위에 반경 동심원 + **실제 근처 인맥의 거리·방위로 계산한 점**(이름
   이니셜 원형, 거리 칩, 같은 주소 묶음은 숫자 배지). 표시 수 상한을 두고
   넘치면 묶음/생략.
4. 카드 안에 정직 표기: **"거리·방향 기준 표시 (실제 지도가 아님)"** — 이
   문구는 빼지 않는다(과장 금지 원칙).
5. "지도로 보기" 버튼 → 기존 지도 화면(nearby_map_view). 탭 동작은 기존
   카드와 동일 유지.
6. 위치 동의 없음·근처 0명일 때의 빈 상태를 각각 설계 — 가짜 점 금지.

⚠️ 주의:
- map.jpg 일러스트를 걷어낼 때, 그 카드에 걸린 기존 동작(위치 토글 연동,
  탭 시 지도 열기 — F-13·F-11 관련 회귀 방지 주석들)을 깨지 않는다.
- `radar_view.dart`의 기존 회귀 방지 테스트와 #401이 새로 넣은 지역 구획
  표시와의 배치 관계를 확인한다(카드가 커지므로 화면 구성 재점검).

## 검증

두 건 다 **부분 테스트**(규약 표 제시는 착수 시점에 PM이 사용자에게):
⑤ 상세 시트 열기 → 아이콘 동작(전화·문자·메일 인텐트 발화 확인) → 빈 값
줄 아이콘 없음 → 닫기·편집 · ⑥ 주변 탭 → 카드 표시·점 배치·빈 상태 →
지도 진입 → #401 지역 구획과의 공존. `flutter analyze` 증가 0 · 기존
테스트 회귀 0 + 새 로직(점 배치 계산 등) 테스트 추가.
