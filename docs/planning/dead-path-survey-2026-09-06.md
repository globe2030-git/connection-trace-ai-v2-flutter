## 1. 찾은 것

### 🚨 ① `isGateEnabled` — **부르는 곳도 지키는 것도 없다**

```
lib/core/services/phone_verification_service.dart:170
  static Future<bool> isGateEnabled() async { … }

이름 참조   **1건**(정의 그 자체)
테스트      **0건**
```

**무엇이 안 도나**: 번호 인증 **게이트가 켜졌는지** 판정하는 함수인데 **아무도 안
본다.**

**왜 그런가**: 게이트가 아직 꺼져 있다(`config/phoneVerification` 문서 자체가 없다).
**켤 때 부를 자리를 미리 낸 것**으로 보인다.

**그래서 무슨 일이 나나**: 🚨 **켜는 날 조용히 안 걸릴 수 있다.** 위 셋(§③④⑤)과
다른 점이 여기다 — **테스트가 0건**이라 **「안 걸린다」가 빨간불로 안 나타난다.**
[추가 645] 가 *"「신규 가입자만」이 말뿐이었다 — 스위치를 켜면 기존 회원 전원이
인증 화면에 갇힌다"* 로 이미 한 번 이 자리를 겪었다.

**고치는 비용**: 🚨 **지금 「고칠」 것이 없다** — 부를 자리가 4단계 화면과 함께
생긴다. ⭐ **대신 지금 할 수 있는 것은 테스트를 붙이는 것**이고, 그게 싸다.
⚠️ 다만 오늘 규약에 들어간 *"「없다」 검사는 짝이 있어야 뜻을 갖는다"* 대로
**「켜면 걸린다」와 「꺼져 있으면 안 걸린다」를 짝으로** 잠가야 한다.

### ⚠️ ② `pendingCount` — 테스트만 부른다

```
lib/core/services/terms_consent_service.dart:177    앱 참조 0 · 테스트 3
```

동의 저장 **재시도 대기 건수**를 세는 조회용 함수다. **안 불려도 재시도 자체는
돈다** — 이 함수는 「보는 창」이지 「도는 것」이 아니다.

🚨 **다만 이 저장소가 겪은 것이 정확히 그 반대였다** — CLAUDE.md 4장의
*"재시도 로직이 죽어 있었다. 서비스는 정상, **부르는 쪽이 없었다**"*. **그때
드러난 방법이 「기기 저장소 덤프」였다.** ⭐ **`pendingCount` 가 그 창인데 아무도
안 본다면, 다음에 같은 일이 나도 같은 방법으로 찾아야 한다.**

**고치는 비용**: 낮다 — 관리자 화면이나 진단 로그에 한 줄 붙이면 된다.
⚠️ 다만 **값이 있는지는 별개다.** 안 봐도 되는 창일 수 있다.

## 2. 🚨 세는 법 — **그리고 내가 만든 허수 셋**

이 축에서는 **도구가 양쪽으로 다 틀린다.** 실제로 겪은 것을 적는다.

| 세는 법 | 못 본 것 | 결과 |
|---|---|---|
| `export` 참조 0건 | **타입**(추론으로 쓰임) · **진입점**(플랫폼이 부름) | 33건 중 **대부분이 허수** |
| `grep -A6` 로 payload 확인 | 오프셋이 6줄을 넘음 | `receiptData` 를 **「앱이 안 보낸다」로 오판** — 과금 경로였다 |
| `\bname\s*\(` 로 호출 셈 | **tear-off** `.map(fn)` | `formatCommunicationLog` 를 **「아무도 안 부른다」로 오판** |
| `\bname\b` 로 이름 셈 | **흔한 이름** | `start` 가 **196건**(`startsWith` 등) |

⭐ **가장 싼 판별법은 「주석을 읽는 것」이었다.** 의도된 것 넷이 **전부 스스로
「지금은 안 불린다」고 적어 두었다.** 🚨 **grep 을 아무리 정교하게 해도 「의도인지
결함인지」는 안 나온다** — 그건 사람이 적어 둔 자리에만 있다.

📌 **그래서 ①이 값진 이유도 여기다** — `isGateEnabled` 만 **그 설명이 없다.**
