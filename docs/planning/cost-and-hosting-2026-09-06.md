> 여기를 이용할지."*

| 명함 사진 저장 (2,000장 보유자) | **연 ₩261** · 1인 **4원/월** | `card-photo-storage-cost-spec` |

### 🚨 **AI 원가가 전체의 89%인데 실측이 없다**

```
₩65.8 / ₩74.3 = **89%**
근거      tool/analyze_ai_cost.py 가 스스로 **"1,000원당 10회는 잠정치"** 라고 적음
실측 표본  🚨 **aiAuditLogs 0건** (2026-09-06 서버 조회)
```

⭐ **손익계산서에서 가장 먼저 재야 할 것이 이것이다.** 89%를 차지하는 값이
**잠정치**이면 나머지를 아무리 정확히 세도 소용이 없다.

⚠️ **0건인 이유는 안 쟀다** — 지운 적이 없는데 0이었다(PM 조회). 「안 쓴 것」인지
「기록이 안 남는 것」인지 갈리지 않았다. **후자면 그것 자체가 결함이다.**

### 규모별 (1인당 ₩74.3 · **곱셈일 뿐 실측 아님**)

```
    100명  ≈ ₩7,430        1,000명  ≈ ₩74,300      10,000명  ≈ ₩743,000
```

⚠️ **이것은 계산이다.** 무료 등급이 규모에 따라 흡수하는 부분을 안 뺐고, AI 원가가
잠정치라 **위 셋 다 ±89% 흔들릴 수 있다.**

### 🚨 잊기 쉬운 고정비 — CI

규약 3장이 적어 두었다: *"3일 만에 무료분이 바닥나 CI 가 통째로 멈췄다"* (추가 257).
**이용자 수와 무관하게 나가는 돈**이고 **이미 겪었다.** ⬜ **현재 사용량은 못 쟀다.**

## 4. 홈페이지 — Firebase Hosting vs 내부 개발서버

### 🚨 먼저: **아낄 돈이 0에 가깝다**

```
지금 규모   5MB · 방문 거의 없음
무료 등급   저장 341MB · 전송 360MB/일
→ **지금도 앞으로 한참도 $0 이다**
```

⭐ **그러므로 이 결정은 「무료 vs 얼마」가 아니라 「무료 vs 무료 + 관리 부담」이다.**

### 무엇이 걸려 있나 — 🚨 **밖에 등록된 주소들이다**

```
connection-sense.web.app        앱스토어 · 카카오 · 네이버에 등록돼 있다
connectionsense.co.kr/legal/*   방침 · 약관 — **앱이 읽고 스토어가 심사한다**
```

⚠️ **죽으면 로그인과 심사가 깨진다.** 홍보 페이지가 죽는 것과 무게가 다르다.

### 옮기면 우리가 지는 것

| | Firebase Hosting | 내부 개발서버 |
|---|---|---|
| 돈 | **$0** (무료 등급 안) | 서버 유지비 + 회선 |
| 가용성 | Google SLA | 🚨 **우리 책임** — 죽으면 로그인·심사가 깨진다 |
| SSL 인증서 | 자동 갱신 | **갱신 실패 = 앱이 방침을 못 읽음** |
| DDoS·CDN | 포함 | 우리 몫 |
| 보안 패치 | 없음(정적 호스팅) | **웹서버를 계속 패치해야 한다** |
| 배포 | `firebase deploy --only hosting` | 새 절차를 만들어야 한다 |
| **사람 시간** | ≈ 0 | 🚨 **이것이 가장 큰 비용일 수 있다** |

### ⭐ 셋이 아니라 **갈래가 넷**이다

```
갑  전부 Firebase 유지          지금 그대로. 돈 $0
을  전부 내부로                 🚨 방침·약관까지 우리 책임이 된다
병  **부분** — 홍보는 내부, 법적 문서는 Firebase
    ⭐ 죽었을 때 깨지는 것으로 가른 것이다
정  전부 내부 + Firebase 를 **예비**로 남김
    ⚠️ 두 벌을 유지해야 하고, 이 저장소는 오늘 「두 벌로 갈라져 한쪽만 고쳐진」
       사고를 겪었다([추가 696] 파기 경로) — **두 벌은 공짜가 아니다**
```

📌 **가르는 기준은 「죽으면 무엇이 깨지나」다.**

```
방침·약관이 죽으면    앱이 못 읽고 스토어 심사가 막힌다   → 🚨 못 죽는다
홍보 페이지가 죽으면   방문자가 못 본다                  → 복구할 시간이 있다
```

### ⬜ 이 비교가 못 본 것

```
⬜ 내부 개발서버가 **지금 있는지** · 사양 · 회선 · 남는 용량
   🚨 없으면 **새로 사는 비용**이 들어가고, 그러면 비교가 통째로 달라진다
⬜ 그 서버의 현재 관리자가 누구이고 시간이 있는지
⬜ 도메인·DNS 를 어디서 관리하는지 (Cloudflare 계정을 못 찾은 기록이 있다 — 추가 654)
```
