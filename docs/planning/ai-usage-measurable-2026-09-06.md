# `aiAuditLogs` 가 0건이었던 이유 — 그리고 **원가는 잴 수 있다** (2026-09-06)

> PM 지시. 손익계산서(`#871`)에서 **1인당 원가의 89%가 AI 무료 20회**인데
> `aiAuditLogs` 가 0건이라 **표본이 없다**고 적었다. 그 0건을 갈랐다.
>
> ⭐ **결론: 0건은 결함이 아니고, 원가는 다른 자리에서 잴 수 있다.**

---

## 1. 0건의 원인 — **탈퇴하면 지워진다. 설계대로다**

```
functions/src/index.ts:1734  export const onUserDeletedCleanup = onDocumentDeleted(
                    :1778    .collection("aiAuditLogs").where("uid", "==", uid)
                             → batch.delete
```

주석이 *"AI 호출 감사 로그 삭제(추가 112)"* 라고 적어 두었고, 방침의 **「탈퇴 시
파기」**를 따른 것이다.

### 세 갈래를 갈랐다

```
(가) 기록 코드가 없다        ❌ **있다** — writeAiAuditLog (index.ts:816)
                              성공(1004)·실패(1021) **양쪽 경로**에서 부른다
(나) 기록이 실패하고 있다     ❌ **아니다** — 실패하면 logger.warn("aiAuditLog 기록 실패")
                              가 남는데 **90일간 0건**(Cloud Logging 조회)
(다) 안 쓴 것이다            ❌ **아니다** — 아래 §2 처럼 **실제로 썼다**
→ **(라) 썼고 기록됐는데, 그 사람들이 탈퇴해 지워진 것**
```

⚠️ **그러므로 「원가를 영영 못 잰다」는 틀렸다.** 다만 **`aiAuditLogs` 로는 못 잰다** —
탈퇴한 사람의 것은 **설계상 사라지고, 그것이 옳다.**

🚨 **그리고 이건 앞으로도 그렇다.** 이용자가 탈퇴할 때마다 **그 사람의 사용 기록이
원가 계산에서 빠진다.** 원가를 `aiAuditLogs` 로만 세면 **항상 과소 집계된다.**

## 4. ⭐ 덤으로 나온 것 — **429가 10%다**

```
429(한도 초과) 21건 / 205건 = **10.2%**
```

🚨 **열 번에 한 번은 한도에 막혔다.** 이것은 원가가 아니라 **제품 신호**다 —
한도가 낮은 것인지, 특정 이용자가 몰아 쓴 것인지, 재시도가 도는 것인지 **안 갈렸다.**

⚠️ **이 문서는 그것까지 안 쟀다.** 다만 **손익계산서에서 「AI 원가」를 볼 때 「막힌
10%」도 함께 봐야 한다** — 막힌 호출은 **돈은 안 쓰지만 이용자는 못 쓴 것**이다.

상한**이다.
