## B. ✏️ 2장 — `--squash` 는 **PR 본문을 안 담는다**

**어디에**: 32행 *"이 저장소의 커밋 메시지는 나중에 원인을 추적하는 1차 자료로

🚨 결과: `git log 98b1cd32` 본문에 **없던 보안 사고가 있었다고** 적힌 줄이 남았다

### 제안 문안


## C. ✏️ 4-2 — ④(다중집합)는 **줄을 고칠 때 셈법이 다르다**

**어디에**: 464행 ④ 설명, 476행 *"사라진 줄이 있으면 그 줄을 그대로 보여 준다"* 옆

### 왜 — **지금 규약대로 재면 정상을 유실로 읽는다**

규약은 **「사라진 줄 0」만 정상**으로 적어 두었다. 그런데 **줄을 고치면**:

```
줄을 더하면   사라진 0 · 더한 N        ← 규약이 상정한 경우
줄을 고치면   **사라진 1 · 더한 1**    ← 유실처럼 보인다
```

2026-09-05에 `backlog` 682 한 줄을 고쳤더니 정확히 1/1 이 나왔다.

### 제안 문안

```markdown
⚠️ **④는 「줄을 고칠 때」 셈법이 다르다.** 줄을 **더하면** 사라진 0 이지만,
줄을 **고치면 사라진 1 · 더한 1** 이 나온다 — 옛 줄이 사라지고 새 줄이
더해진 것으로 잡히기 때문이다.

📌 **그때는 유실이 아니라 수정이다.** 사라진 줄과 더한 줄의 **앞 40자를
맞대어** 같은 항목인지 보면 갈린다.
```

## D. ✏️ 4-2 — 파이프는 **`git checkout` 만의 문제가 아니다**

**어디에**: 535행 `❌ git checkout -q B 2>&1 | tail -2` 블록

### 왜 — **그 절을 읽은 사람이 같은 날 다시 걸렸다**

지금 그 절은 **브랜치 체크아웃 이야기로만** 적혀 있다. 그래서 **파이프 일반의
문제로 안 읽힌다.**

2026-09-05에 `python3 tool/check_admin_sync.py | tail -3 ; echo $?` 가 **항상 0**
을 냈고, 하마터면 *"검출은 하는데 CI 는 통과한다"* 는 **없는 결함**을 보고할 뻔했다.
파이프를 걷으니 **깨끗할 때 0 · 변조 시 1** 로 정상이었다.

### 제안 문안

```markdown
🚨 **이것은 `git checkout` 만의 문제가 아니다.** 파이프를 걸면 `$?` 는 **마지막
명령의 것**이 되므로, **종료 코드를 보려는 명령에는 파이프를 걸지 않는다.**
출력이 길면 **파일로 받아서 본다.**

    ❌ cmd | tail -3 ; echo $?          →  tail 의 코드
    ✅ cmd > 로그 2>&1 ; echo $?         →  cmd 의 코드

⚠️ 2026-09-05에 `check_admin_sync.py` 를 이렇게 재서 **없는 결함을 보고할
뻔했다.** 위 절을 읽은 세션이 같은 날 걸렸다 — **브랜치 이야기로만 적혀 있어
자기 상황으로 안 읽혔다.**
```

## 안 넣는 것 다섯 — **왜 안 넣는지**

| 나온 것 | 왜 안 넣나 |
|---|---|
| `git log --since=<날짜>` 가 0건을 낸다(시각을 붙여야) | **추가 664 「세는 도구가 못 보는 것」이 이미 덮는다.** 도구별 함정을 하나씩 적기 시작하면 끝이 없다 |
| 「이미 적혀 있다」 전에 `git log -S` | **「조회한 값은 조회한 순간의 것」이 덮는다.** ⚠️ 다만 결이 하나 새롭다 — **「이미 있다」가 「오늘 내가 넣은 것」일 수 있다.** 규약을 늘리기보다 **E 의 예시로 읽히면 된다** |
| `dart format` 을 디렉터리 단위로 돌리면 analyze 가 는다 / CI 는 `dart format` 을 안 본다 | **값이 낮다.** 겉모습이고 되돌리기 쉽다. ⭐ 다만 **3장의 「CI 가 못 보는 것」 목록에 한 줄** 더할 값은 있다 — globe2030님이 원하시면 |
| **실물 확인** — 기억·요약·전언으로 말하지 않는다 (globe2030님 지시) | 🚨 **안 넣는 것이 아니라 이미 4장 전체가 그것이다.** 계산/실측 · 세는 도구 · 요약이 원본 행세 · 출처를 함께 옮긴다 — 전부 이 지시의 다른 얼굴이다. **비어 있던 한 칸이 「기억」이고 그것이 E 다** |
| `brew uninstall` 이 의존성을 물고 간다(node 가 사라졌다) | **규약이 아니라 런북 소재다.** 「새 노트북에 원래 없던 것」이 아니라 **오늘 제거로 사라진 것**이라 1-1 절과 성격이 다르다(PM 확인) |
