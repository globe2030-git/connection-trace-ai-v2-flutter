1총칙

커넥션센스는 명함을 기반으로 인맥을 관리하고, 오랜만에 연락하는 상대와 자연스럽게 대화를 이어갈 수 있도록 돕는 서비스입니다. 회사는 이용자가 안심하고 서비스를 이용할 수 있도록 다음과 같은 원칙으로 개인정보를 처리합니다.

  • 서비스 제공에 필요한 최소한의 정보만 수집합니다.
  • 이용자의 동의 없이 제3자에게 정보를 제공하지 않습니다(법령에 따른 경우 제외).
  • AI 기능처럼 정보를 외부로 전송하는 기능은 매번 전송 항목을 화면에 보여주고 별도 동의를 받은 뒤에만 동작합니다.
  • 이용자는 언제든지 앱 안에서 본인 정보를 열람·수정·삭제할 수 있습니다.

4보유 및 이용 기간

원칙적으로 개인정보는 회원 탈퇴 시까지 보유하며, 탈퇴 즉시 지체 없이 파기합니다. 다만 다음의 경우는 예외로 합니다.

  • 관계 법령에서 일정 기간 보존을 요구하는 경우, 해당 법령에서 정한 기간 동안 보관
  • 이용자가 앱 안에서 개별 명함을 삭제하는 경우, 해당 명함 정보는 즉시 삭제됩니다

7AI 서비스 연동에 관한 사항

AI 대화 브리핑은 선택 기능이며, 사용하지 않아도 서비스의 다른 기능을 그대로 이용할 수 있습니다.

  • AI에게 무엇을 보낼지는 요청할 때마다 화면에 표시되며, 이용자가 확인하고 동의해야만 전송됩니다. 백그라운드에서 자동으로 전송되는 정보는 없습니다.
  • 전송 항목은 상대방 명함 요약, 이용자 본인 프로필 요약, 이용자가 선택한 소통 기록, 참고용 날씨 정보로 한정됩니다.
  • 이용자가 직접 발급한 API 키를 등록하는 방식(BYOK)을 이용 중인 경우, 그 키는 기기에만 저장되고 회사 서버를 거치지 않습니다.
회사는 향후 AI 기능을 회사가 제공하는 서버 경유 방식으로 전환할 계획입니다. 전환 시에는 "이용자 기기 → AI 제공사" 직접 전송이 "이용자 기기 → 회사 서버 → AI 제공사" 경로로 바뀌며, 이 방침도 함께 개정되어 사전 고지됩니다.

8타인의 정보를 입력하는 경우

이 서비스는 성격상 이용자가 만난 사람의 명함 정보를 등록하게 되므로, 이용자 본인이 아닌 제3자(거래처 담당자 등)의 개인정보가 이용자에 의해 입력될 수 있습니다.

  • 회사는 이용자가 입력한 명함 정보를 그 이용자 본인의 인맥 관리 목적으로만 저장·백업하며, 다른 이용자나 제3자와 공유하지 않습니다.
  • 이용자는 자신이 등록하는 제3자의 정보를 수집·보관·이용함에 있어 관계 법령(개인정보 보호법 등)을 준수할 책임이 있습니다.
  • 명함 속 인물 본인이 자신의 정보 삭제를 원하는 경우, 아래 13. 개인정보 보호책임자 연락처로 문의하면 확인 후 조치합니다.

9이용자의 권리와 행사 방법

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 열람·정정 — 앱 내 "내 프로필", "명함 상세" 화면에서 직접 확인·수정
  • 삭제 — 명함 개별 삭제는 각 명함 화면에서, 계정 전체 삭제는 설정 → 계정 삭제 메뉴에서 즉시 처리
  • 처리 정지 요구 — 아래 개인정보 보호책임자 연락처로 요청

계정을 삭제하면 서버에 백업된 프로필·명함 데이터가 함께 삭제되며, 이 처리는 되돌릴 수 없습니다.

10파기 절차 및 방법

보유 기간이 끝나거나 이용자가 삭제를 요청한 개인정보는 지체 없이 파기합니다.

  • 전자적 파일 형태로 저장된 정보는 복구할 수 없는 방법으로 영구 삭제합니다.
  • 계정 삭제 시 서버(Firestore)에 저장된 해당 이용자의 프로필 문서와 명함 데이터 전체가 삭제됩니다.

11안전성 확보 조치

  • AI API 키 등 민감한 인증 정보는 기기의 보안 저장소(Keychain/Keystore)에 암호화하여 저장합니다.
  • 명함·프로필 데이터는 기기 저장 시와 서버 저장 시 모두 AES-256 방식으로 암호화됩니다. 이를 통해 권한 없는 제3자의 접근으로부터 보호합니다.
  • 서버에 저장된 데이터는 본인 계정으로 인증된 이용자만 접근할 수 있도록 접근 권한을 제어합니다.
  • AI로 전송되는 정보는 매 요청마다 별도 화면에서 항목을 고지하고 동의를 받습니다.
  • 명함 원본 사진은 현재 서버로 전송·저장하지 않으며 기기 내에만 보관됩니다.
