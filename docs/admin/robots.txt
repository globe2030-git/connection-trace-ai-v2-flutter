# 커넥션센스 관리자 콘솔 — 검색 노출만 줄인다.
#
# 🚨 robots.txt 는 **접근을 막는 장치가 아니다**(docs/site/robots.txt 의
# 같은 주석 참고). 크롤러에게 하는 부탁일 뿐이라 주소를 아는 사람에게는
# 그대로 열린다. 이 콘솔을 실제로 막는 것은 이 파일이 아니라 **로그인**
# (Firebase Auth + firestore.rules 의 관리자 판정)이다.
#
# 그러므로 이 파일이 하는 일은 딱 하나 — 검색엔진 색인에서 빠지게 하는
# 것뿐이다. 관리자 콘솔은 로그인 없이는 어차피 데이터를 못 읽지만, 검색
# 결과에 "커넥션센스 관리자 콘솔" 같은 페이지가 노출되는 것 자체가 불필요한
# 관심을 끈다. index.html <head> 의 <meta name="robots" content="noindex,
# nofollow"> 가 실제 차단 역할을 하고, 이 파일은 크롤러가 페이지를 열어
# 그 메타태그를 읽기 전에도 미리 걸러지도록 돕는 보조 수단이다.

User-agent: *
Disallow: /
