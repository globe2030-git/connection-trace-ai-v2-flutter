# 리퍼럴(추천인) 프로그램 — 실행 스펙

성장 엔진 1순위(무료 유입의 ~35% 목표). 현금이 아니라 **AI 회차 증정**으로
굴린다 — 손익분석상 회차 원가는 판매가의 3~5%뿐이라 증정 비용이 극소.

---

## 1. 보상 구조

| 대상 | 보상 | 지급 시점 |
|---|---|---|
| 초대자 | AI 브리핑 **+5회** | 피초대자가 **활성화**(명함 1장 등록 + AI 1회 사용)했을 때 |
| 피초대자 | AI 브리핑 **+5회** (가입 체험 10회에 추가) | 초대 링크로 가입 완료 시 |

- **지급을 "활성화" 기준으로** — 단순 설치가 아니라 실제 사용을 보상해야
  허수·어뷰징이 준다. 피초대자 보상은 가입 시 즉시(유입 유인), 초대자
  보상은 활성화 시(품질 유인)로 비대칭 설계.
- **상한**: 초대자 1인당 월 최대 10명(50회)까지 보상. 그 이상은 안내만.
  (어뷰징·원가 폭주 방지. 상한은 실측 후 조정.)

## 2. 어뷰징 방지

- 회차 잔액은 **서버 전용 필드**(`firestore.rules`의 `clientWritableUserFields()`
  에 넣지 말 것 — 잔액=현금). 보상 지급은 Cloud Functions에서만.
- 같은 기기·같은 결제수단·동일 IP 반복은 카운트 제한.
- 자기초대(같은 계정) 차단, 탈퇴 후 재가입 재보상 차단(기기 지문/해시).

## 3. 트리거 & 카피 (가치 체감 직후 요청)

**언제**: AI 브리핑을 한 번 유용하게 쓴 직후가 최적(가치를 막 체감한 순간).
설정 메뉴에 상시 진입점도 둔다.

**카피 예시**:
> 방금 그 한마디, 동료도 필요하지 않을까요?
> 지금 초대하면 두 분 모두 AI 브리핑 5회를 드려요.
> [초대 링크 공유]

공유 문구(피초대자가 받는 메시지):
> [이름]님이 커넥션센스를 추천했어요. 오래 연락 못한 고객에게 무슨 말을
> 걸지 AI가 만들어주는 앱이에요. 이 링크로 받으면 AI 브리핑 15회를 드려요.
> [스토어 링크]

## 4. 측정

- **k-factor** = (초대로 유입된 활성 유저 수) / (초대한 유저 수). 목표 ≥ 0.4.
- 초대→가입→활성화 퍼널 각 단계 이탈률.
- 미달 시: ① 보상 회차 상향(원가 여력 큼) ② 요청 시점/카피 A/B
  ③ 공유 마찰 축소(원탭 카톡 공유).

## 5. 구현 메모 (개발 착수 시)

- 딥링크/초대코드 발급·귀속(누가 누굴 초대했나). Firebase Dynamic Links 대안
  검토(종료 예정이므로 앱 자체 초대코드 + 스토어 링크 방식 권장).
- 회차 원장(ledger): 지급/차감 이력 서버 기록(정산·감사용).
- **과금 파라미터 확정(사용자 결정) 후 착수.** 보안 규칙 검토 필수.
