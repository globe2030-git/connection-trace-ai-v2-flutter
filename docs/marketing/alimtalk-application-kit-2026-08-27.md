# 카카오 알림톡 신청 준비물 — 월요일(2026-08-31) 착수용

> 작성 2026-08-27(목) · 용도: **휴대폰 인증번호 발송 전용**. 광고성 발송은 하지 않는다.
> 발송 대행사는 **알리고**(HANDOFF 기록). 홈페이지는 이미 게시돼 있다
> (<https://connectionsense.web.app>, 저장소 소스 `docs/site/`).

## 🚨 먼저 알아야 할 것 — **월요일에 「템플릿 심사 신청」 버튼은 못 누른다**

기록에는 *"알림톡 심사 신청 마감 ~9/1, 10 영업일"*로 한 덩어리로 적혀 있는데,
**실물은 한 덩어리가 아니라 앞뒤로 물린 체인 4개**다. 그리고 **템플릿 심사는
그 체인의 마지막 칸**이다.

```
① 카카오톡 채널 개설            즉시            ← 월요일에 됨
② 비즈니스 채널 심사(비즈니스 인증)  영업일 3~7일   ← 🚨 여기가 목이다. 카카오가 심사한다
③ 알리고 가입 + 발신프로필 등록    ②가 끝나야 됨
④ 템플릿 등록 → 카카오 심사       영업일 2일 이내(카카오 공식)
```

⚠️ **③은 ②의 승인 없이는 시작조차 안 된다.** 발신프로필은 **비즈니스 인증을 받은
채널만** 등록할 수 있다(근거 6-3). 그러니 월요일에 ④를 신청하는 것은
**물리적으로 불가능**하다 — ②만으로 최소 영업일 3일이 필요하다.

📌 **그래서 「10 영업일」이라는 숫자는 틀리지 않았다. 다만 그것은 ④ 하나가 아니라
①~④ 전체에 걸리는 시간이다.** 카카오 공식 문서상 ④ 자체는 **영업일 2일 이내**다.

**날짜로 놓으면 이렇다**(오늘 2026-08-27 목요일 기준, 공휴일 없다고 봄):

| | 최선(②가 3영업일) | 최악(②가 7영업일) |
|---|---|---|
| ① 채널 개설 · ② 심사 신청 | 08-31(월) | 08-31(월) |
| ② 승인 | 09-03(목) | 09-09(수) |
| ③ 발신프로필 등록 | 09-03~09-04 | 09-09~09-10 |
| ④ 템플릿 심사 신청 | **09-04(금)** | **09-10(목)** |
| ④ 승인 | **~09-08(화)** | **~09-14(월)** |

⚠️ **단, 이 표는 「크림하우스 명의의 카카오톡 채널이 아직 없다」는 전제다.**
이미 채널이 있고 비즈니스 인증까지 끝나 있으면 **월요일에 ④까지 갈 수 있다.**
→ **2번 항목의 첫 질문이 그것이다. 이 답 하나로 일정이 갈린다.**

## 1. 월요일 아침 체크리스트

> 위에서 아래로 순서대로. **앞 칸이 끝나야 뒤 칸이 열린다.**
> 각 줄의 근거는 6번(근거 조사)에 URL과 함께 있다.

### 0단계 — 시작 전에 손에 쥐고 있어야 할 것 (5분)

```
□ 사업자등록증 파일 (jpg/png/pdf)         — ② ③ 둘 다에서 첨부한다
□ 대표자 명의 휴대폰 (본인인증용)          — ②에서 대표자 휴대폰 본인인증을 한다
□ 고객센터 전화번호 1개                   — ⚠️ 홈페이지에 전화번호가 없다(5번 참조)
□ 카카오계정 (앞으로 채널 마스터가 될 계정) — 이 계정이 채널 주인이 된다. 신중히 고른다
```

⚠️ **채널 마스터 계정은 나중에 넘기기 번거롭다.** 개인 카카오계정으로 만들면
그 사람이 계속 마스터다. **회사 대표 계정으로 만들 것을 권한다.**

### 1단계 — 카카오톡 채널 개설 (약 10분, 즉시 완료)

<https://center-pf.kakao.com> → 새 채널 만들기

```
□ 카카오계정 로그인 → 카카오비즈니스 통합회원 전환
□ 관리자 이름 입력          한글·영문·숫자·점(.) 최대 10자
□ 휴대폰 인증               ⚠️ 1일 5회 제한이 있다. 잘못 눌러 소진하지 말 것
□ 채널(프로필) 이름 입력     → "커넥션센스"
□ 검색용 아이디 입력         → "connectionsense" 희망 (선점됐으면 대안 준비)
```

⚠️ **검색용 아이디는 못 바꾼다.** 그리고 ③(발신프로필 등록)에서 이 아이디를
그대로 쓴다. **오타 없이, 결정한 다음에 입력한다.**

### 2단계 — 채널 설정 3개를 켠다 (약 5분)

알림톡을 보내려면 **채널이 아래 상태여야 한다**(카카오 공식).

## 3. 템플릿 문구 초안 (휴대폰 인증번호)

### 3-1. 본문 초안 — **이대로 붙여 넣으면 된다**

```
[커넥션센스] 휴대폰 인증

요청하신 인증번호는 #{인증번호} 입니다.
3분 안에 앱 화면에 입력해 주세요.

본인이 요청하지 않았다면 다른 분이 번호를 잘못 입력했을 수 있습니다.
인증번호는 누구에게도 알려주지 마세요.
```

**변수**: `#{인증번호}` 1개 · **예시 텍스트**(필수 입력): `123456`
**버튼**: **넣지 않는다** · **부가정보·이미지·대표링크**: 사용 안 함

### 3-2. 이 초안이 피한 반려 사유 — 하나씩 대조

카카오 공식 심사 가이드의 A(정보성)·B(서비스 기준)·C(발송 불가) 조건에 맞춰 봤다.

| 흔한 반려 사유 | 이 초안은 |
|---|---|
| **정보성이 아니다**(광고성) | 회원가입·본인확인은 **계약 체결·이행에 필요한 필수 정보**다. 홍보 문구 0 |
| **앱 설치를 유도한다** (C 조건 명시) | 「앱 다운로드」·스토어 링크·설치 버튼 **없음**. *"앱 화면에 입력"*은 이미 앱을 쓰는 사람에게 하는 안내다 |
| **채널 추가를 유도한다** | 채널추가형 아님, 문구 없음 |
| **변수로만 이루어져 있다** (반려 사유 명시) | 고정 문장이 대부분, 변수는 1개 |
| **변수가 40개를 넘는다** | 1개 |
| **변수에 예시 텍스트가 없다** (전 변수 필수) | `123456` 입력 |
| **버튼명·미리보기에 변수가 들어갔다** | 버튼 없음, 미리보기 사용 안 함 |
| **형식화되지 않는다**(사람마다 내용이 달라진다) | 인증번호만 다르고 나머지는 항상 같다 = B 조건 충족 |
| **수신자의 사전 행동이 안 보인다** | *"요청하신"* 한 단어로 명시했다 |
| 1,000자 초과 | 약 110자 |

### 3-3. 변수 표기 규칙 — 확인한 것과 못 한 것

```
✅ 확인   표기는 #{변수명} 형태  (예: #{인증번호})
✅ 확인   모든 변수에 예시 텍스트를 넣어야 한다 (카카오 공식 심사 가이드)
✅ 확인   변수 40개 초과 금지 / 변수로만 구성 금지 / 버튼명·미리보기에 변수 금지 (공식)
🟡 부분   본문 1,000자 제한 — 대행사 문서 다수가 같은 값을 안내. 카카오 원문에서는 미확인
🟡 부분   변수 개수 자체의 상한은 없으나 "치환값이 많아 의미 파악이 어려우면 반려"
❌ 미확인 변수명에 쓸 수 있는 문자(한글 가능 여부·길이) — 원문에서 못 찾았다
          → 알리고 콘솔의 안내를 그 자리에서 확인할 것
```

### 3-4. 🚨 보안 템플릿 — **반드시 체크한다**

> *"템플릿 보안 시 모바일 외의 디바이스에서 메시지 내용이 노출되지 않습니다.
> ('모바일에서 확인해주세요' 문구 노출)"*

**OTP·인증번호·비밀번호는 보안 체크가 사실상 필수**다. 체크하지 않고 등록하면
**카카오 검수 과정에서 보안 상태로 바뀔 수 있다**고 대행사 문서들이 공통으로 안내한다.

📌 **이 앱은 제3자 개인정보를 다룬다.** PC 카카오톡에 인증번호가 그대로 뜨는 것은
계정 탈취 경로가 된다. **체크하지 않을 이유가 없다.**

### 3-5. 대체발송(SMS) 문구 초안 — ⚠️ 쓸지 말지부터 정해야 한다

카카오톡을 안 쓰는 사람에게는 알림톡이 안 간다. SMS로 대체발송할 수 있는데,
**그건 문자라서 「발신번호 사전등록」이 따로 필요하다**(통신서비스 이용증명원 등).

```
[커넥션센스] 요청하신 인증번호는 #{인증번호} 입니다. 3분 안에 입력해 주세요.
```

→ **2번 표의 9번 질문**으로 사용자 결정을 받는다.

## 7. 이 문서를 쓰면서 바로잡은 것 — 기록에 남긴다

| 기존 기록 | 실물 | 무엇이 달랐나 |
|---|---|---|
| *"알림톡 심사 신청 마감 9/1, 10 영업일"* | 템플릿 심사 자체는 **영업일 2일 이내**(카카오 공식) | **10 영업일은 체인 전체**다. 템플릿 심사만 보면 훨씬 짧고, **진짜 목은 비즈니스 채널 심사 3~7영업일**이다 |
| *"사용자만 신청할 수 있다"* | 맞다 — **채널 마스터만** 비즈니스 심사를 신청할 수 있다 | 근거가 확인됐다 |
| *"홈페이지가 필요하다"* | 이미 있고, 사업자 정보도 이미 들어 있다 | **필요한 건 홈페이지가 아니라 「고객센터 전화번호」**였다 |

📌 **「신청 마감 9/1」을 「그날 신청하면 된다」로 읽으면 안 된다.** 09-01(화)에
①을 시작하면 템플릿 승인은 **9월 중순**이 된다. **월요일(08-31)에 ①②를 여는 것이
현실적으로 가장 이른 출발선이다.**
