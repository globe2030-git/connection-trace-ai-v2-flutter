### 0단계 — 시작 전에 손에 쥐고 있어야 할 것 (5분)

```
□ 사업자등록증 파일 (jpg/png/pdf)         — ② ③ 둘 다에서 첨부한다
□ 대표자 명의 휴대폰 (본인인증용)          — ②에서 대표자 휴대폰 본인인증을 한다
□ 고객센터 전화번호 1개                   — ⚠️ 홈페이지에 전화번호가 없다(5번 참조)
□ 카카오계정 (앞으로 채널 마스터가 될 계정) — 이 계정이 채널 주인이 된다. 신중히 고른다
```

**선점 여부도 같이 보인다.**

## 3. 템플릿 문구 초안 (휴대폰 인증번호)

### 3-1. 본문 초안 — **이대로 붙여 넣으면 된다**

```
[커넥션센스] 휴대폰 인증

요청하신 인증번호는 #{인증번호} 입니다.
3분 안에 앱 화면에 입력해 주세요.

본인이 요청하지 않았다면 다른 분이 번호를 잘못 입력했을 수 있습니다.
인증번호는 누구에게도 알려주지 마세요.
```

**변수**: `#{인증번호}` 1개 · **예시 텍스트**(필수 입력): `123456`
**버튼**: **넣지 않는다** · **부가정보·이미지·대표링크**: 사용 안 함

### 3-2. 이 초안이 피한 반려 사유 — 하나씩 대조

카카오 공식 심사 가이드의 A(정보성)·B(서비스 기준)·C(발송 불가) 조건에 맞춰 봤다.

| 흔한 반려 사유 | 이 초안은 |
|---|---|
| **정보성이 아니다**(광고성) | 회원가입·본인확인은 **계약 체결·이행에 필요한 필수 정보**다. 홍보 문구 0 |
| **앱 설치를 유도한다** (C 조건 명시) | 「앱 다운로드」·스토어 링크·설치 버튼 **없음**. *"앱 화면에 입력"*은 이미 앱을 쓰는 사람에게 하는 안내다 |
| **채널 추가를 유도한다** | 채널추가형 아님, 문구 없음 |
| **변수로만 이루어져 있다** (반려 사유 명시) | 고정 문장이 대부분, 변수는 1개 |
| **변수가 40개를 넘는다** | 1개 |
| **변수에 예시 텍스트가 없다** (전 변수 필수) | `123456` 입력 |
| **버튼명·미리보기에 변수가 들어갔다** | 버튼 없음, 미리보기 사용 안 함 |
| **형식화되지 않는다**(사람마다 내용이 달라진다) | 인증번호만 다르고 나머지는 항상 같다 = B 조건 충족 |
| **수신자의 사전 행동이 안 보인다** | *"요청하신"* 한 단어로 명시했다 |
| 1,000자 초과 | 약 110자 |

### 3-3. 변수 표기 규칙 — 확인한 것과 못 한 것

```
✅ 확인   표기는 #{변수명} 형태  (예: #{인증번호})
✅ 확인   모든 변수에 예시 텍스트를 넣어야 한다 (카카오 공식 심사 가이드)
✅ 확인   변수 40개 초과 금지 / 변수로만 구성 금지 / 버튼명·미리보기에 변수 금지 (공식)
🟡 부분   본문 1,000자 제한 — 대행사 문서 다수가 같은 값을 안내. 카카오 원문에서는 미확인
🟡 부분   변수 개수 자체의 상한은 없으나 "치환값이 많아 의미 파악이 어려우면 반려"
❌ 미확인 변수명에 쓸 수 있는 문자(한글 가능 여부·길이) — 원문에서 못 찾았다
          → 알리고 콘솔의 안내를 그 자리에서 확인할 것
```

### 3-4. 🚨 보안 템플릿 — **반드시 체크한다**

> *"템플릿 보안 시 모바일 외의 디바이스에서 메시지 내용이 노출되지 않습니다.
> ('모바일에서 확인해주세요' 문구 노출)"*

**OTP·인증번호·비밀번호는 보안 체크가 사실상 필수**다. 체크하지 않고 등록하면
**카카오 검수 과정에서 보안 상태로 바뀔 수 있다**고 대행사 문서들이 공통으로 안내한다.

📌 **이 앱은 제3자 개인정보를 다룬다.** PC 카카오톡에 인증번호가 그대로 뜨는 것은
계정 탈취 경로가 된다. **체크하지 않을 이유가 없다.**

### 3-5. 대체발송(SMS) 문구 초안 — ⚠️ 쓸지 말지부터 정해야 한다

카카오톡을 안 쓰는 사람에게는 알림톡이 안 간다. SMS로 대체발송할 수 있는데,
