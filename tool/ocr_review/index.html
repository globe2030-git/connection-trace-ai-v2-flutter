실물과 인식 결과를 나란히 놓고 정답을 남기는 도구

  1. TSV 불러오기 — 관리자 화면의 일괄 스캔에서 저장한 scan_result.tsv (원문 칸이 있어야 합니다)
  2. 이미지 폴더 — card_01.png 같은 원본이 든 폴더 (건너뛰어도 됩니다)
  3. 한 장씩 보면서 틀린 칸만 고치고 Ctrl+Enter로 다음 장
  4. 끝나면 정답지 내보내기
이 도구는 네트워크를 쓰지 않습니다. 명함은 제3자의 개인정보라, 파일을 브라우저 안에서만 읽고 아무 데도 보내지 않습니다. 진행 상황은 이 브라우저에만 저장됩니다. 검수가 끝나면 내보낸 정답지를 안전한 곳에 두세요.
