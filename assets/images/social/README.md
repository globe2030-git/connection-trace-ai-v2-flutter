# 소셜 로그인 공식 버튼 애셋

⚠️ **여기 있는 파일은 우리가 만든 것이 아니다.** 각 제공자가 배포하는 공식
버튼 이미지이고, **형태·색·문구를 바꿀 수 없다.**

## 카카오

`developers.kakao.com` 에서 받은 "카카오 로그인" 완성형 버튼(한국어).

```
kakao_login_wide.png          300×45   (완성형, 넓은 형)
2.0x/kakao_login_wide.png     600×90   (같은 것의 2배)
kakao_login_narrow.png        183×45   (완성형, 좁은 형) — 지금은 안 쓴다
2.0x/kakao_login_narrow.png   366×90
```

`2.0x/` 는 Flutter 의 해상도별 애셋 규칙이다. `large` 가 `medium` 의 **정확히
2배**라 그대로 얹을 수 있었다(600×90 = 300×45 × 2).

### ⚠️ 지켜야 하는 규정 (공식 가이드 원문)

> - "심볼 없이 카카오 로그인 버튼을 구성할 수 없습니다"
> - "기능 아이콘을 카카오 로그인 버튼의 심볼로 사용할 수 없습니다"
> - "컨테이너 박스의 radius는 12 픽셀로 적용합니다"
> - "위의 색상 규정에 벗어난 색상을 적용해서는 안 됩니다"
> - "컨테이너의 크기에 따라 심볼과 레이블 크기 비율을 유지하여 확대합니다"
> - "컨테이너의 좌, 우 방향으로 동일하게 확장합니다"

📌 **넓히는 방향은 허용된다.** 다만 *"비율을 유지하여"* 이므로 **이미지를
가로로만 늘이면 안 된다.** 그래서 화면 폭에 맞출 때는 이미지를 늘이지 않고,
같은 노란색 컨테이너를 넓히고 그 위에 이미지를 **원래 비율로 얹는다.**

⚠️ **심볼만 떼어 우리 버튼의 아이콘으로 쓰는 것은 금지다.** 그래서 완성형
버튼 이미지를 통째로 쓴다.

## 네이버

로그인 버튼 리소스가 아니다. 공식 "네이버 로그인" 버튼을 받기 전까지 네이버
버튼에는 로고를 넣지 않는다 — 흉내 내는 것보다 없는 편이 낫다.
