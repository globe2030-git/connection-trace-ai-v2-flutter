# /flutter-developer

`$ARGUMENTS`를 그대로 `flutter-developer` 서브에이전트(`Agent` 도구, `subagent_type: flutter-developer`)에게 위임한다. 좁고 구체적인 기술 작업(리팩터링, 버그 수정)에 적합 — 무엇을 만들지부터 정해야 하는 열린 요청이면 `/flutter-planner`를 대신 쓰라고 안내한다.
