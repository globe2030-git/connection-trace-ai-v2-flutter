# /flutter-planner

`$ARGUMENTS`를 그대로 `flutter-planner` 서브에이전트(`Agent` 도구, `subagent_type: flutter-planner`)에게 위임한다. 인자가 비어 있으면, 무엇을 검토/기획해야 하는지 사용자에게 먼저 물어본다.

이 명령은 이 저장소(`connection-trace-ai-v2-flutter`)를 작업 디렉토리로 CLI를 실행 중일 때만 의미가 있다 — `flutter-planner`는 이 프로젝트 전용이다.
